5　Langmuir–Hinshelwood 单分子反应　A → B

机理 A + * ⇌ A*（快，平衡）　→　A* → B*（慢，速控步，速率常数 k）　→　B* ⇌ B + *（快，平衡）
"吸附平衡"意味着 θ_A、θ_B 可以直接用 4.3 节的竞争 Langmuir 式。
公式 $$r=k\,\theta_A=\frac{k\,K_Ap_A}{1+K_Ap_A+K_Bp_B}$$

初速率（还没有产物，p_B = 0）：

$$r_0=\frac{kK_Ap_A}{1+K_Ap_A}$$
推导：表观级数 n_A = 1 − θ_A，n_B = −θ_B 表观级数的严格定义是对数斜率 \(n_i=\partial\ln r/\partial\ln p_i\)。取对数： $$\ln r=\ln(kK_A)+\ln p_A-\ln(1+K_Ap_A+K_Bp_B)$$ 对 ln p_A 求导：第二项给 1；第三项给 \(p_A\cdot\dfrac{K_A}{1+K_Ap_A+K_Bp_B}=\theta_A\)。所以 $$n_A=1-\theta_A,\qquad n_B=-\frac{K_Bp_B}{1+K_Ap_A+K_Bp_B}=-\theta_B$$ 物理含义：空位比例决定了速率还能随 p_A 增长多少；产物占多少位点，就把速率压低多少。
两种极限
  • 弱吸附或低压（K_Ap_A ≪ 1）：r ≈ kK_Ap_A，一级。表面大部分空着，压力翻倍，A* 翻倍。
  • 强吸附或高压（K_Ap_A ≫ 1）：r ≈ k，零级。表面已被占满，再加压也挤不上更多 A。
  • 产物强吸附（K_Bp_B ≫ 1 + K_Ap_A）：r ≈ kK_Ap_A/(K_Bp_B)，对 B 为 −1 级，对 A 为一级。
图 F2　左：LH 单分子速率曲线（橙点为题 11 / J3-1 的数据）；右：表观级数 n = 1 − θ 随压力从 1 降到 0
应用
  • 线性化求 k 和 K：\(\dfrac1{r_0}=\dfrac1k+\dfrac{1}{kK_A}\cdot\dfrac1{p_A}\)，1/r 对 1/p 作直线，截距 1/k，K = 截距/斜率。
  • 两点求级数再求 θ、K：\(n=\ln(r_2/r_1)/\ln(p_2/p_1)\)，对应 \(p=\sqrt{p_1p_2}\)（ln p 坐标的中点），再由 θ = 1 − n，\(K=\theta/[p(1-\theta)]\)。见题 11。
  • 经典实例：PH₃ 在 W 上分解——低压一级、高压零级；NH₃ 在热 W 或 Mo 表面分解——零级（表面饱和）；N₂O 在 Au 上分解——一级（弱吸附）。

6　Langmuir–Hinshelwood 双分子反应　A + B → P

机理A、B 都先吸附在同一种位点上（竞争吸附，快平衡），再由相邻的 A* 与 B* 在表面反应（速控步）。
公式 $$r=k\,\theta_A\theta_B=\frac{k\,K_AK_B\,p_Ap_B}{(1+K_Ap_A+K_Bp_B)^2}$$
推导 1：表观级数 $$\ln r=\text{const}+\ln p_A+\ln p_B-2\ln(1+K_Ap_A+K_Bp_B)$$ $$n_A=1-2\theta_A,\qquad n_B=1-2\theta_B$$ θ_A > 1/2 时 n_A < 0：负级数，加 A 反而变慢。
推导 2：速率最大值 固定 p_B，令 ∂r/∂p_A = 0（等价于 n_A = 0）： $$(1+K_Ap_A+K_Bp_B)-2K_Ap_A=0\ \Rightarrow\ K_Ap_A=1+K_Bp_B$$ 此时 \(\theta_A=\dfrac{1+K_Bp_B}{2(1+K_Bp_B)}=\dfrac12\)。也就是说，A 占满一半位点时速率最大；再多就把 B 挤走了。
为什么最大点的级数是 0：级数是 ln r–ln p 曲线的斜率，\(n=\dfrac{p}{r}\dfrac{dr}{dp}\)。山顶处 dr/dp = 0，所以 n = 0；山顶左边速率随 p_A 上升（n > 0），右边下降（n < 0）。
推导 1 的另一种看法：拆成两部分 因为 r = kθ_Aθ_B，对 A 的级数 = θ_A 对 p_A 的级数 + θ_B 对 p_A 的级数：
  • A 自己的覆盖度 θ_A = K_Ap_A/D：和单分子一样，级数 1 − θ_A（A 越多越接近饱和）。
  • B 的覆盖度 θ_B = K_Bp_B/D：分子不含 p_A，只有分母变大，加 A 只会把 B 挤走，级数 −θ_A。
合起来 \(n_A=(1-\theta_A)+(-\theta_A)=1-2\theta_A\)：加 A 的好处减去挤走 B 的损失。单分子反应没有"挤走 B"这一项，所以只有 1 − θ_A。
级数之和：从两个级数直接读出空位比例 $$n_A+n_B=(1-2\theta_A)+(1-2\theta_B)=2(1-\theta_A-\theta_B)=2\theta_*$$ 测出对 A、对 B 的两个级数，就能直接得到空位比例 θ_* = (n_A + n_B)/2，不需要知道任何 K。两种吸附物都很强时 θ_* → 0，于是 n_A ≈ −n_B。
B 解离吸附（B₂ + 2* ⇌ 2B*）时 $$\theta_B=\frac{\sqrt{K_Bp_B}}{D},\quad D=1+K_Ap_A+\sqrt{K_Bp_B},\qquad r=\frac{k\,K_Ap_A\sqrt{K_Bp_B}}{D^2}$$ $$n_A=1-2\theta_A,\qquad n_B=\tfrac12-\theta_B,\qquad n_A+2n_B=2\theta_*$$ n_B 的来历：分子 √p_B 给 ½；分母里 √(K_Bp_B) 对 ln p_B 求导也带 ½，乘上系数 −2 得 −θ_B。解离吸附的级数整体减半：范围是 +½ 到 −½。典型例子：Pt 上乙烯加氢（H₂ 解离），见题 20。
物理图像反应要求 A* 和 B* 挨在一起。A 太少没得反应，A 太多 B 没地方待——"自中毒"（self-poisoning）。这也是 Sabatier 原理的动力学版本：吸附既不能太弱，也不能太强。
应用：Pt 上 CO 氧化 低温下 CO 吸附极强，表面几乎全是 CO（θ_CO → 1），O₂ 找不到空位，速率对 CO 呈负级数（约 −1）：CO 越多反应越慢。升温使 CO 部分脱附、空出位点，速率突然跃升，这就是汽车尾气催化剂的"起燃"（light-off）。见题 16。

7　Eley–Rideal 机理

机理只有 A 吸附；B 从气相直接撞上 A* 反应：A* + B(g) → P。
公式 $$r=k\,\theta_A\,p_B=\frac{k\,K_Ap_A\,p_B}{1+K_Ap_A},\qquad n_A=1-\theta_A\ (0\sim1),\qquad n_B=1$$
变体 A 解离吸附的 ER：\(r=k\,p_B\,\dfrac{\sqrt{K_Ap_A}}{1+\sqrt{K_Ap_A}}\)，\(n_A=\tfrac12(1-\theta_A)\)，n_B = 1。
双位点 LH（A、B 吸附在两种不同的位点上，互不竞争）：\(r=k\,\dfrac{K_Ap_A}{1+K_Ap_A}\cdot\dfrac{K_Bp_B}{1+K_Bp_B}\)，n_A = 1 − θ_A，n_B = 1 − θ_B，都在 0 到 1 之间。

负级数只可能来自"两种吸附物抢同一种位点"。如果速率随 p_A 单调上升并饱和，说明 A 没有挤走 B：要么是 ER（B 不吸附），要么是双位点 LH。再看对 B 的级数：ER 恒为 1，双位点 LH 会随 p_B 从 1 降到 0。

8　Mars–van Krevelen 机理（氧化还原机理）

机理 用于氧化物催化剂上的选择氧化（V₂O₅、MoO₃、钼酸铋、CeO₂ 等）。位点不是"空/被占"，而是"氧化态 / 还原态"：
  1. 还原：反应物 A 夺走表面晶格氧生成产物，氧化态位点变成还原态。速率 \(k_Ap_A\,\theta_{Ox}\)。
  2. 再氧化：O₂（记作 B）把还原态位点重新氧化。速率 \(k_Bp_B\,\theta_{Red}\)。
证据：用 ¹⁸O₂ 做实验，产物里最先出现的是晶格里的 ¹⁶O——氧来自催化剂本身，而不是直接来自气相 O₂。
推导 每个位点非氧化即还原：\(\theta_{Ox}+\theta_{Red}=1\)。稳态时被还原的速率 = 被氧化的速率（否则 θ_Ox 会一直变）： $$k_Ap_A\,\theta_{Ox}=k_Bp_B\,(1-\theta_{Ox})\ \Rightarrow\ \theta_{Ox}=\frac{k_Bp_B}{k_Ap_A+k_Bp_B}$$ $$r=k_Ap_A\,\theta_{Ox}=\frac{k_Ak_B\,p_Ap_B}{k_Ap_A+k_Bp_B}\qquad\Longleftrightarrow\qquad \frac1r=\frac{1}{k_Ap_A}+\frac{1}{k_Bp_B}$$ 倒数形式像串联电阻：还原和再氧化两步串联，哪一步慢，总速率就由哪一步决定。
级数：\(n_A=1-\dfrac{k_Ap_A}{k_Ap_A+k_Bp_B}=\theta_{Ox}\)，\(n_B=1-\theta_{Ox}=\theta_{Red}\)，所以 n_A + n_B = 1，两者都在 0 到 1 之间，不会出现负级数。
为什么分母里没有"1" 两种模型的分母都是"位点所有状态的权重之和"。Langmuir 竞争吸附里位点有三种状态：空位（权重 1）、A*（K_Ap_A）、B*（K_Bp_B），所以分母是 1 + K_Ap_A + K_Bp_B，那个 1 就是空位。MvK 里位点只有氧化态（权重 k_Bp_B）和还原态（权重 k_Ap_A），没有"空着"这个状态，所以没有 1。

  • k_Ap_A ≪ k_Bp_B：表面几乎全是氧化态（θ_Ox → 1），还原步骤决速，r ≈ k_Ap_A，对 A 一级、对 O₂ 零级。很多选择氧化对 O₂ 呈零级，就是这种情况。
  • k_Ap_A ≫ k_Bp_B：表面几乎全是还原态，再氧化决速，r ≈ k_Bp_B，对 A 零级、对 O₂ 一级。
若每转化 1 个 A 需要 γ 个 O₂、对 O₂ 的级数为 m，常写成 \(r=\dfrac{k_Ap_A\,k_Bp_B^{\,m}}{\gamma k_Ap_A+k_Bp_B^{\,m}}\)，结构不变。

9　表观活化能

公式 $$E_{app}\equiv-R\,\frac{\partial\ln r}{\partial(1/T)}=E_{true}+\sum_i n_i\,\Delta H_{ads,i}$$
推导（LH 单分子） \(k=Ae^{-E_{true}/RT}\)，\(K=K_0e^{-\Delta H_{ads}/RT}\)，\(r=kKp/(1+Kp)\)。取对数后对 1/T 求导： $$\frac{\partial\ln r}{\partial(1/T)}=-\frac{E_{true}}{R}-\frac{\Delta H_{ads}}{R}+\theta\,\frac{\Delta H_{ads}}{R}$$ （最后一项来自 \(\partial\ln(1+Kp)/\partial(1/T)=\theta\cdot\partial\ln K/\partial(1/T)\)）。乘以 −R： $$E_{app}=E_{true}+(1-\theta)\,\Delta H_{ads}=E_{true}+n\,\Delta H_{ads}$$
三种情况
  • 低覆盖（一级区）：E_app = E_true + ΔH_ads < E_true。温度升高时 k 变大，但 θ 变小，两者部分抵消，所以测到的活化能偏小。
  • 高覆盖（零级区）：E_app = E_true。表面一直是满的，只剩表面反应本身。
  • 强吸附抑制物（如 CO 自中毒，n_CO = −1）：E_app = E_true − ΔH_CO = E_true + |ΔH_CO|，比真实值大，因为必须先让 CO 脱附腾出位点。
温度跨越覆盖度变化区时，Arrhenius 图会弯曲：低温段陡、高温段缓。

10　速控步判断总表（单分子 A → B，单一位点）

三步：① A + * ⇌ A*（K_A）；② A* ⇌ B*（表面反应，平衡常数 K_s = θ_B/θ_A）；③ B* ⇌ B + *（K_B）。哪一步慢，其余两步就处于平衡，用平衡关系求各覆盖度：

速控步平衡的两步给出速率式（远离总平衡）表面主要是对 A 的级数加入产物 B
A 的吸附θ_B = K_Bp_Bθ_*，θ_A = θ_B/K_s\(r=\dfrac{k_ap_A}{1+K_Bp_B(1+1/K_s)}\)空位（无产物时）恒为 1抑制，n_B = −(θ_A + θ_B)
表面反应θ_A = K_Ap_Aθ_*，θ_B = K_Bp_Bθ_*\(r=\dfrac{k_sK_Ap_A}{1+K_Ap_A+K_Bp_B}\)A*1 − θ_A（1 → 0）抑制，n_B = −θ_B
B 的脱附θ_A = K_Ap_Aθ_*，θ_B = K_sθ_A\(r=\dfrac{k_dK_sK_Ap_A}{1+(1+K_s)K_Ap_A}\)B*θ_*（常接近 0）基本无影响，n_B ≈ 0

脱附控制时 θ_B 由 A 的平衡决定；气相 B 重新吸附是慢步骤的逆过程，同样很慢，所以远离平衡时加入产物几乎不影响速率。数值对比见题 22。

注意 这是 Hougen–Watson 初速率分析的标准结论。严格地说，如果表面反应 A* ⇌ B* 的平衡常数不大，脱附控制时 θ_B 也会随 p_A 按 Langmuir 形式变化，同样表现为 1 → 0。这时还要看产物分压、总压或温度的影响才能分清。考试按上表作答即可，但要会说出这个前提。
从数据判断机理的步骤
  1. 测不同 p_A 下的初速率，两点或作图求表观级数 n。
  2. 看 n 是否随压力变化：恒为 1 → 吸附控制或弱吸附；1 → 0 → 表面反应控制（LH 单分子）；接近 0 且加产物不变 → 脱附控制；出现负值 → 双分子 LH 自中毒。
  3. 双分子反应再测对 B 的级数：n_A + n_B = 2θ_*（LH 竞争）；n_B 恒为 1（ER）；n_A + n_B = 1（MvK）。
  4. 线性化（1/r 对 1/p）求 k 和 K，检验两段算出的 K 是否一致——一致说明模型自洽。
  5. 测不同温度：由 E_app 与 n 的关系 \(E_{app}=E_{true}+n\Delta H_{ads}\) 分离出真实活化能和吸附热。
