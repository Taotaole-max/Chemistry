# 表面吸附与表面反应动力学：公式推导 · 应用 · 题库

- `表面吸附与表面反应动力学_公式推导应用题库.pdf`：成品，21 页（一页速查 + 9 节推导与应用 + 17 题含答案）
- `head.html`：样式、封面、一页速查表
- `part1.html`：第 1–4 节（撞墙通量、粘附与吸附速率、脱附与 TPD、Langmuir 等温式与吸附热）
- `part2.html`：第 5–9 节（LH 单分子、LH 双分子、Eley–Rideal、表观活化能、速控步判断）
- `part3.html` / `part4.html`：题库 1–9 / 10–17
- `tail.html`：结尾标签
- `make_figures.py`：生成 `fig/` 里的 7 张图（需要 matplotlib、numpy，中文字体用文泉驿正黑）
- `render_pdf.js`：拼接 HTML，用 MathJax 把 TeX 公式渲染成 SVG，再用 Chromium 打印 PDF（需要 npm 包 mathjax@3、playwright-core）

重编：`python make_figures.py && node render_pdf.js 表面吸附与表面反应动力学_公式推导应用题库.pdf`
注意：公式里（$$…$$、\(…\)）不要写中文，MathJax 渲染不了。
