# Figures

All 8 report figures are generated by code in `figures/`. See **`figures/README.md`**
for the full explanation, the reproduce command, and the per-figure / data provenance.

Short version: Matplotlib + RDKit, run `python figures/make_all.py`, output goes to
`figures/output/` as SVG + PNG, `build_docx.py` embeds the SVGs. No AI-generated,
downloaded, or traced images.

## History (why the figure set changed shape)

- Started as 7 planned figures (OUTLINE v3), grew to 19 while adding a per-material
  monomer + chain-structure figure for every subsection, then an appendix.
- 2026-08-28: consolidated back down. Dropped the appendix; merged the many small
  per-material figures into multi-panel composites (Fig 3 = all repeat units,
  Fig 4 = all higher-order structure, Fig 5 = thermal + mechanical); dropped the
  processing flowchart (its logic is now prose in §6). Final set: **8 figures**,
  body back to 10 pages.
- `figures/style.py` was rewritten so every figure exports at a fixed 170 mm width
  (no more per-figure size drift) and molecules render through one shared helper.
