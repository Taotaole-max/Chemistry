## 3. Structure and Properties of Representative Biopolymers — 850 词 ★核心

每种材料只写：**重复单元 → 关键分子间作用 → 由此决定的一个标志性性质 → 一个短板**。数值进 Table 1。

### 3.1 Polysaccharides（330 词）
- **Cellulose**（120 词）：β-1,4 链的带状构象；分子内 O3–H···O5 + 链间氢键片层 → 结晶度 60–70%；**~300 °C 分解先于熔融 → 不可熔融加工**；晶体轴向模量约 130 GPa
  ⚙️ 色散校正周期性 DFT 给 Iα/Iβ 稳定性与内聚能（1 句）
- **Starch**（80 词）：直链/支链、颗粒半结晶、回生；**Tg 随含水量剧变 → 性能随湿度漂移**
- **Chitosan**（70 词）：脱乙酰度同时决定溶解性与分子量（内在权衡）；pKa ≈ 6.5 → 稀酸中成聚阳离子
  ⚙️ 隐式溶剂下的质子化自由能（半句）
- **Alginate**（60 词）：M/G 嵌段与 Ca²⁺ egg-box 配位 → 室温离子凝胶；G 含量↑ 模量↑ 脆性↑

### 3.2 Polyesters（280 词）
- **PHB/PHA**（150 词）：Tm ≈ 175 °C、Tg ≈ 4 °C、结晶度 55–70%；二次结晶 → 存放后变脆；**六元环 cis-消除的分解温度紧邻 Tm → 加工窗口极窄**；共聚降 Tm 的对策
  ⚙️ 过渡态计算给 cis-消除能垒（1 句）
- **PLA**（110 词）：丙交酯 ROP；L/D 立体化学决定结晶性；**Tg ≈ 60 °C 是耐热天花板**；结晶慢需成核剂；sc-PLA 的 Tm 升至约 230 °C
  ⚙️ CH···O 相互作用能解释 Tm 提升（半句）
- **PBS / PEF**（20 词，各一句）

### 3.3 Protein-based（150 词）
- **Silk fibroin**（70 词）：GAGAGS → β-折叠纳米晶 + 无定形基体的两相结构 → 强度与韧性兼得（生物聚合物中罕见）
- **Collagen/gelatin**（50 词）：三股螺旋、变性—凝胶转变
- **序列确定 → Đ = 1**（30 词，引到 §4）

### 3.4 Lignin and Natural Rubber（90 词）
- 木质素：无规交联网络 → 无定形、Tg 宽泛、批次异质
- 天然橡胶：超高 MW + **应变诱导结晶 → 自增强**

## 4. Molecular Weight and Its Distribution — 280 词 ★

- Mn / Mw / Đ / DP 与性质的关系（60 词）
- **三类分布及其成因**（100 词）：蛋白与核酸 Đ = 1.00（模板合成）；多糖 Đ 1.5–10 且**分布是工艺的函数**；PHA 与 PLA 居中
- **MW → 性质**（60 词）：缠结与熔体强度；降解使 MW 下降 → **力学性能远早于质量损失就崩塌**
- **测量的困难与后果**（60 词）：溶解、聚集、支化；**脱离测试方法的 MW 数据不可比**

## 5. General Property Patterns — 400 词 ★横向总结

- **5.1 热行为**（110 词）：分解温度贴近或低于 Tm 是这一类材料的通病；根源是氢键密度高、熔融所需能量接近键断裂能 → 加工窗口窄
  📊 **Fig 4** 热性质图：Tg / Tm / Td 三点并排，直接显示加工窗口宽窄
- **5.2 力学**（100 词）：高结晶 + 强氢键 → 高模量、低断裂伸长；缺柔性链段与缠结
  📊 **Fig 5** Ashby 图：模量 vs 断裂伸长，对照 PE/PP/PET
- **5.3 亲水性与阻隔**（90 词）：极性主链 → 吸湿 → 增塑软化、阻隔随湿度崩塌
  ⚙️ 无定形盒子 MD 给自由体积与渗透系数（半句）
- **5.4 降解作为材料性质**（100 词）：聚酯水解（端羧基自催化 → 本体侵蚀）vs 多糖/蛋白酶解（受结晶度与可及表面控制）；**结晶度既给强度、又挡水、也挡降解——全文的核心矛盾**
  📊 **Fig 6** 降解路径示意
  ⚙️ 酯水解三条路径的能垒对比（1 句）

## 6. Processing — 160 词

- 熔融加工的边界：干燥要求（PLA 不干燥 → MW 断崖）、PHB 的窄窗口
- 非熔融路线：溶液流延、湿法纺丝、Lyocell
- 配方对策：增塑剂、成核剂、共混增容、纳米纤维素增强
- 判断句：多数"性能不足"实为**加工窗口不足**

## 7. Advantages and Disadvantages Compared with Synthetic Polymers — 300 词

- **优势**（120 词）：可再生碳源、生物相容与可吸收、固有功能性（抗菌/手性/生物识别）、环境中可降解
- **劣势**（150 词，用数字）：价格、耐热（PLA 的 HDT）、阻隔（OTR/WVTR）、脆性与老化、吸湿、**批次波动**、回收流污染
- **总结句**（30 词）：短板集中在热与湿，不在强度；输在通用替代，赢在专用场景

## 8. Applications — 300 词

每个应用先说**需要什么性质**，再说哪种材料满足：
- 包装（80 词）：阻隔 + 韧性 + 耐热 → 多层/涂层/共混；活性包装
- 生物医用（100 词）：生物相容 + 可控降解速率 → PGA/PLGA 缝线、控释（酸性降解产物问题）、支架、水凝胶与生物打印
- 农业（50 词）：土壤降解 + 一季力学寿命 → 地膜
- 纺织与其他（70 词）：Lyocell、PLA 纤维；胶黏剂、柔性电子

## 9. Current Status, Challenges and Outlook — 180 词

- 产能规模与材料分布（一句带最新数据，体现时效性）
- 三个技术瓶颈：**加工窗口、吸湿与阻隔、批次一致性**——都回到性质
- 原料迭代与化学/酶法解聚回单体（一句）
- ⚙️ 数据驱动的性质预测：QSPR/ML 预测 Tg 与降解速率（一句）

## 10. Conclusions — 120 词

三条判断，每条一句：
1. 性能瓶颈是**热与湿**，不是强度
2. **结晶度**是核心矛盾变量：给强度、挡水、也挡降解
3. 分子量必须连测试方法一起报告，否则不可比
