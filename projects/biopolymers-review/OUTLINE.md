## 1. Introduction and Definition — 300 词，0.6 页

- 生物聚合物的定义：由生物体合成、或由生物质衍生单体聚合得到的大分子（IUPAC 口径，一段话说完，**不展开术语争论**）
- 为什么值得单独研究：它们是自然界演化出的高分子，结构上有合成高分子做不到的三个特征——**序列确定性、手性纯度、高度有序的氢键网络**，这三点正是本文要讲的性质来源
- 一句话交代：本文关注结构与性质，可降解性作为**材料性质**在 §5.4 讨论，不讨论环境政策与标签问题

## 3. Structure and Properties of Representative Biopolymers — 1,800 词，3.4 页 ★核心

每种材料统一四步走：**重复单元 → 链构象与分子间力 → 聚集态与热转变 → 力学/溶解性能与短板**

### 3.1 Polysaccharides（700 词）
- **Cellulose**：β-1,4 葡聚糖、糖苷键交替翻转 → 平直带状链；分子内 O3–H···O5 锁构象、链间氢键成片、片间 vdW 堆叠 → 结晶度 60–70%；**分解（~300 °C）先于熔融**，因此不可熔融加工；晶体轴向模量约 130 GPa；溶剂体系（NaOH/尿素、LiCl/DMAc、NMMO、离子液体）；纳米纤维素 CNC/CNF 的模量与长径比
  ⚙️ 色散校正周期性 DFT 给 Iα/Iβ 相对稳定性与内聚能——"为何不熔融、为何难溶"的分子级依据
- **Starch**：直链/支链结构、颗粒半结晶 A/B/C 型、糊化与回生；TPS 的甘油增塑，**Tg 随含水量剧烈变化**（水即增塑剂）→ 性能随湿度漂移
- **Chitin / Chitosan**：α/β 甲壳素晶型；脱乙酰度 DD 同时决定溶解性与分子量（脱乙酰过程降解主链——一个内在权衡）；壳聚糖 pKa ≈ 6.5 → 稀酸中成聚阳离子
  ⚙️ 隐式溶剂（PCM/SMD）下的质子化自由能，解释 pH 响应溶解
- **Alginate**：M/G 嵌段序列；Ca²⁺ 与 GG 段的 egg-box 配位 → 室温离子凝胶；G 含量↑ 模量↑ 脆性↑

### 3.2 Polyesters（500 词）
- **PHB / PHA**：细菌胞内合成；Tm ≈ 175 °C、Tg ≈ 4 °C、结晶度 55–70%；**二次结晶导致存放后变脆**；六元环 cis-消除的热分解起始温度紧邻 Tm → **加工窗口极窄**；共聚（PHBV、PHBHHx）如何降 Tm 与结晶度
  ⚙️ 过渡态搜索给 cis-消除能垒，把"窗口窄"从经验变成机理
- **PLA**：丙交酯开环聚合；L/D/meso 立体化学决定结晶性；PLLA Tg ≈ 60 °C（耐热天花板）、Tm ≈ 175 °C、结晶速率慢 → 需成核剂；**sc-PLA 立构复合物 Tm 升至约 230 °C**
  ⚙️ CH···O 弱氢键与堆叠的相互作用能（需色散校正），解释 ~50 °C 的 Tm 提升
- **PBS / PEF** 各两行

### 3.3 Protein-based（350 词）
- **Silk fibroin**：GAGAGS 重复 → β-折叠纳米晶分散于无定形基体；silk I/II 转变；强度与韧性的结构来源
- **Collagen / gelatin**：Gly-X-Y 三股螺旋、羟脯氨酸稳定作用、变性—凝胶转变
- **Zein / casein / soy protein**：成膜性
- **关键性质**：序列确定 → **Đ = 1**，天然的"完美"分布（引到 §4）

### 3.4 Lignin & Natural rubber（250 词）
- 木质素：G/S/H 苯丙烷单元、β-O-4 为主的无规网络 → 无定形、Tg 宽泛、批次异质
- 天然橡胶：cis-1,4-聚异戊二烯、超高 MW、**应变诱导结晶**带来自增强

## 4. Molecular Weight and Molecular Weight Distribution — 500 词，1.0 页 ★

题目点名的子话题，也是最容易写深的一节。

- **基本量**：Mn、Mw、Đ、DP，以及各自对性质的影响
- **三类分布，成因不同**：
  - 蛋白质/核酸：模板合成 → **Đ = 1.00，严格单分散**，合成高分子无法企及
  - 多糖：酶促延伸 + 提取降解 → Đ 宽（1.5–10），**分布本身是工艺的函数**
  - PHA（Đ ≈ 1.5–3，链转移控制）、PLA（取决于 ROP 控制水平）
- **MW 如何决定性质**：缠结分子量与熔体强度；强度随 Mn 上升趋于饱和；降解使 MW 下降 → **力学性能远早于质量损失就崩塌**
- **测量为什么难**（本节的批判性重点）：纤维素需铜氨/LiCl-DMAc 或衍生化；多糖聚集使 SEC 失真；支化破坏等效流体力学体积 → 需 SEC-MALS 或黏度法；Mark–Houwink 参数缺失；MALDI 的高质量歧视
- **判断句**：文献中同一材料的 MW 常差一个数量级，**脱离测试方法的 MW 数据不可比**

## 5. General Property Patterns — 700 词，1.4 页 ★

不再逐个材料讲，而是**横向总结生物聚合物作为一类材料的共性**，这是全文最有"综述感"的一节。

- **5.1 热行为**：多数生物聚合物的分解温度与 Tm 太近甚至更低 → 加工窗口窄；根源是主链极性基团多、氢键密度高，熔融所需能量接近键断裂能
  📊 **Fig 5** 热性质图：各材料的 Tg / Tm / Td 三点并排，**一眼看出谁有加工窗口、谁没有**
- **5.2 力学**：高结晶 + 强氢键 → 模量高、断裂伸长低（脆）；缺乏柔性链段与缠结；增塑与共聚是主要对策
  📊 **Fig 6** Ashby 图：模量 vs 断裂伸长，生物聚合物 vs PE/PP/PET
- **5.3 亲水性与阻隔**：极性主链 → 吸湿 → 增塑软化、尺寸不稳、阻隔性随湿度崩塌；这是包装应用的核心障碍（对比 PET/EVOH）
  ⚙️ 无定形盒子 MD 给自由体积与渗透系数，说明短板在自由体积还是在极性
- **5.4 降解行为（作为材料性质）**：聚酯走水解（端羧基自催化 → 本体侵蚀 vs 表面侵蚀）；多糖/蛋白走酶解，速率受结晶度和可及表面控制 —— **结晶度既给强度又挡降解，这是本领域的核心矛盾**
  ⚙️ 中性/酸/碱催化酯水解的能垒对比 + 溶剂化自由能

## 6. Processing — 350 词，0.7 页

- 熔融加工的边界：干燥要求（PLA 挤出前不干燥 → MW 断崖）、PHB 的窄窗口、热历史对结晶度的影响
- 不可熔融体系的路线：溶液流延、湿法纺丝、静电纺、Lyocell
- 配方手段：增塑剂（及迁移）、成核剂、共混与增容（PLA/PBAT、TPS/PLA）、纳米纤维素增强
- 一句批判：多数生物聚合物的"性能不足"其实是**加工窗口不足**，而不是分子结构不行

## 7. Advantages and Disadvantages Compared with Synthetic Polymers — 650 词，1.3 页

- **优势**：可再生碳源；生物相容与可吸收；固有功能性（抗菌、手性、生物识别、自组装）；可在环境中降解（用词严格：注明测试环境）
- **劣势（用数字）**：价格（$/kg 对比 PE/PP）；耐热（PLA 的 HDT）；阻隔（OTR/WVTR 对比 PET）；脆性与老化；吸湿；**批次波动**——天然原料的固有问题，也是工业界最头疼的一条；回收流污染
- **一句公允的总结**：短板集中在热与湿，而非强度本身；因此它们输在"通用替代"，赢在"专用场景"
- 简要提一句 EOL：可降解性依赖环境，性能寿命与降解速率的取舍无法同时优化

## 8. Applications — 700 词，1.4 页

按"性质匹配需求"组织，每个应用先说**需要什么性质**，再说哪种材料满足：
- **8.1 包装**：需要阻隔 + 韧性 + 耐热 → 多层结构、涂层、共混；活性包装（壳聚糖抗菌）
- **8.2 生物医用**（最不可替代）：需要生物相容 + 可控降解速率 → PGA/PLGA 缝线与固定件、药物控释（降解产物酸化引发炎症的问题）、支架、水凝胶与生物打印（海藻酸、明胶）
- **8.3 农业**：需要在土壤中降解 + 一季的力学寿命 → 地膜、控释肥包膜
- **8.4 纺织**：Lyocell、PLA 纤维、再生丝素
- **8.5 其他**：胶黏剂、化妆品、柔性电子基底

## 10. Conclusions — 200 词

三条可证伪的判断，例如：
1. 生物聚合物的性能瓶颈是**热与湿**，不是强度
2. **结晶度**是贯穿全领域的核心矛盾变量：给强度、挡水、也挡降解
3. 分子量数据必须连同测试方法报告，否则不可比
