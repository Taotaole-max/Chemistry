# 无机材料化学练习题 A2–B5：详细答案与解析

课程练习卷：`26_Inorg_Mater_Chem_exercises_A2_A3.pdf`、`..._B2_B3.pdf`、`..._B4_B5.pdf`（共 60 题）。

## 文件

| 路径 | 用途 |
|---|---|
| `无机材料化学_A2-B5_练习详细答案与解析.pdf` | **最终交付**：60 题，每题 英文原题 → 题意 → 答案 → 配图 → 解析 → 考点/易错 |
| `content/A2.txt` … `content/B5.txt` | 各 Part 的答案正文（紧凑标记格式，规则见 `scripts/build_pdf.py` 开头注释） |
| `figs/` | 60 张配图 PNG，文件名 = 题号 + 内容 |
| `scripts/common.py` | 作图公用工具：中文字体、简易 3D 球棍投影、流程图方框/箭头 |
| `scripts/figs_A2.py` … `figs_B5.py` | 各 Part 的配图脚本 |
| `scripts/build_pdf.py` | 把 `content/*.txt` 转成 HTML，用无头 Chromium 打印成 PDF |
| `build/` | 中间产物 HTML（已 gitignore） |

## 重新生成

```bash
python -m venv venv && venv/bin/pip install matplotlib numpy rdkit pillow
cd scripts
for f in figs_A2 figs_A3 figs_B2 figs_B3 figs_B4 figs_B5; do ../venv/bin/python $f.py; done
../venv/bin/python build_pdf.py          # 也可只编某几部分：build_pdf.py A2 B4
```

## 说明

- 讲义标注 2026 年跳过的 A3.2、A3.3、A3.5、B4.8–B4.10 也写了答案，题号旁标“2026 不考”。
- B2.5 原题要求“在给定相图上标注”，但练习卷未附相图，按简单共晶相图和匀晶相图两种情况作答。
- 热力学数值（Ellingham 图、Boudouard、碱金属还原 SiO₂）为 298 K 标准值或线性近似，图注已注明“示意”。
