# B3 | 固体合成方法：高温、容器、化学气相输运、溶胶–凝胶
>>> 本部分讲“怎么把固体做出来”：高温固相合成需要的加热手段和容器材料；化学气相输运（CVT）的条件、方向（Schäfer 规则）和实例；软化学的溶胶–凝胶法。

@@ 1 | Give three possibilities to achieve high temperatures for chemical reactions.
?? 举出三种为化学反应提供高温的方法。
>>
- **① 电阻加热炉（resistance furnace）**：电流通过发热体产生焦耳热。发热体决定最高温度：FeCrAl（Kanthal）约 1400 °C、SiC 约 1600 °C、MoSi₂ 约 1800 °C；石墨或 W/Mo 发热体在真空/惰性气氛中可达 2500–3000 °C。管式炉、马弗炉都属此类。
- **② 感应加热（induction heating）**：高频交变磁场在导电的坩埚（石墨、W、Ta）或样品中感应出涡流而发热；升温快、可达约 3000 °C，常与真空/保护气、悬浮熔炼结合。
- **③ 电弧熔炼（arc melting）**：W 电极与样品间产生电弧，样品放在水冷铜炉床上，Ar 保护；温度 > 3000 °C，几分钟熔化高熔点金属/金属间化合物，坩埚不被污染。

（其他可答：激光加热、太阳（聚光）炉、等离子炬、电子束熔炼；化学法——铝热反应 / 自蔓延高温合成 SHS，如 [[Fe2O3 + 2Al]] → [[Al2O3 + 2Fe]]（约 2500 °C）；氢氧焰（Verneuil 法长红宝石）。）
!! B3_01_high_temperature_methods.png | 各种加热手段可达到的温度量级（深色为实验室最常用的三类）
## 选择加热方式要同时考虑：①需要的温度；②气氛（氧化 / 惰性 / 真空）——石墨、W、Mo 发热体在空气中会烧掉，只能在保护气中用，而 SiC、MoSi₂ 能在空气中用，因为表面生成保护性 SiO₂ 膜；③容器是否与样品反应（见 B3.2）。电弧和感应熔炼的优点是热量直接产生在样品/坩埚中，容器（水冷铜）本身是冷的，污染少。
** 答题写三种 + 每种一句原理 + 大致温度即可。

@@ 2 | Why should silica container not be used for the reaction with alkali metals at high temperatures? Which containers can be used?
?? 为什么高温下碱金属的反应不能用石英（SiO₂）容器？可以用什么容器？
>> **原因**：碱金属是极强的还原剂，高温下会**还原 SiO₂** 并把它变成**碱金属硅酸盐**，石英管被腐蚀、变色、变脆直至破裂，产物也被 Si、O 污染。例：
- [[4Li + SiO2]] → [[2Li2O + Si]]（ΔG° ≈ −266 kJ）；
- 对 Na，单纯还原 [[4Na + SiO2]] → [[2Na2O + Si]] 并不有利（ΔG° ≈ +104 kJ），但生成的 [[Na2O]] 立即与 [[SiO2]] 结合：[[4Na + 3SiO2]] → [[2Na2SiO3 + Si]]（ΔG° ≈ −366 kJ），总反应强烈自发。

**可用容器**：不与碱金属反应的**金属安瓿**——**Ta、Nb**（最常用，电弧焊封）、Mo、W、Fe（低碳钢/不锈钢）；金属安瓿外面再套一根抽真空熔封的石英管，防止 Ta/Nb 在高温下被空气氧化。某些情况下也可用致密氧化物坩埚（MgO、Al₂O₃ 对 Na/K），但 Li 会侵蚀它们；石墨不能用（K、Rb、Cs 插层成 [[KC8]]，Li 生成 [[Li2C2]]）。
!! B3_02_alkali_metal_vs_silica.png | (a) 由标准生成 Gibbs 能估算的反应 ΔG°（298 K）；(b) Ta/Nb 安瓿 + 外层石英管的标准做法
## 数据：ΔfG°(SiO₂) = −856 kJ/mol，ΔfG°(Na₂O) = −376，ΔfG°(Li₂O) = −561，ΔfG°(Na₂SiO₃) = −1467 kJ/mol。
- Li：2 × (−561) − (−856) = −266 kJ → 直接还原就能自发（Li₂O 特别稳定）；
- Na：2 × (−1467) − 3 × (−856) = −366 kJ → 靠“碱性氧化物 + 酸性氧化物 SiO₂ 成盐”驱动。
这也说明了一个普遍规律：**酸性的 SiO₂ 容器怕一切强碱性物质**（碱金属、碱金属氧化物/氢氧化物、熔融碱），高温熔碱必须用 Ni、Ag 或 Pt 坩埚（Pt 怕熔碱 + 氧化剂）。
** 关键词：碱金属的强还原性 + 生成硅酸盐；Ta / Nb 管焊封 + 石英外套。

@@ 3 | Which are the two important conditions for applying a chemical transport reaction for a specific compound.
?? 对某一化合物应用化学气相输运反应的两个重要条件是什么？
>>
- **① 固体必须能与输运剂发生可逆的多相反应，并且产物全部是气体**：i A(s) + k B(g) ⇌ j C(g) + …（固体“溶解”进气相，在另一处再沉积出来；输运剂只需少量、循环使用）。
- **② 平衡位置要“居中”**：反应的 ΔrG° ≈ 0，即平衡常数 K ≈ 1（经验上 |lg K| ≲ 4，ΔrG° 在约 ±100 kJ/mol 之内），**并且 ΔrH° ≠ 0**，这样平衡常数随温度明显变化，源区（T₂）和沉积区（T₁）之间才有足够的分压差 Δp 驱动气相扩散。
- 输运方向（Schäfer 规则）：**ΔrH > 0（吸热）→ 从热端输运到冷端（T₂ → T₁）；ΔrH < 0（放热）→ 从冷端到热端（T₁ → T₂）**。
!! B3_03_CVT_conditions.png | (a) 简单模型 A(s) + B(g) ⇌ AB(g)：分压差 Δp 只在 ΔrG° ≈ 0 附近才大；(b) 两个必要条件
## 为什么 K 不能太大或太小？
- K ≫ 1：两端几乎都完全变成气体 AB(g)，分压几乎相同 → Δp ≈ 0，没有净输运（固体只是被“吃掉”）；
- K ≪ 1：两端几乎都不生成气体 → 同样 Δp ≈ 0；
- 只有 K ≈ 1 时，温度改变引起的 K 变化才能转化为显著的分压差。
为什么需要 ΔrH ≠ 0？由 van't Hoff 方程 d ln K / dT = ΔrH°/(RT²)，ΔrH = 0 时 K 不随温度变，两端没有差别。
** 关键词：heterogeneous reversible reaction, all products gaseous；K ≈ 1；ΔH determines direction。

@@ 4 | Give an example of an endothermic/exothermic chemical transport reaction and explain the various steps that occur?
?? 各举一个吸热 / 放热化学输运反应的例子，并解释发生的各个步骤。
>> **吸热输运（热端 → 冷端）**：ZnS 以 I₂ 为输运剂
- **[[ZnS(s) + I2(g)]] ⇌ [[ZnI2(g) + ½S2(g)]]**，ΔrH > 0；源区 T₂ ≈ 900 °C，沉积区 T₁ ≈ 800 °C。
- ① **源区（热）**：高温平衡右移，ZnS 与 I₂ 反应生成气态 ZnI₂ 和 S₂（“溶解”）；
- ② **气相输运**：源区气态产物分压高，经扩散（和对流）移向冷端；
- ③ **沉积区（冷）**：低温平衡左移，ZnS 重新生成并长成单晶（“结晶”）；
- ④ **输运剂回流**：释放出的 I₂ 扩散回源区，继续循环——少量 I₂ 就能输运大量 ZnS。

**放热输运（冷端 → 热端）**：Mond 法提纯镍
- **[[Ni(s) + 4CO(g)]] ⇌ [[Ni(CO)4(g)]]**，ΔrH ≈ −160 kJ/mol
- ① 约 50–80 °C：粗 Ni 与 CO 生成挥发性 [[Ni(CO)4]]（Fe、Co 等杂质几乎不反应）；② [[Ni(CO)4]] 扩散到热区；③ 约 200 °C：分解析出高纯 Ni（99.99 %）；④ CO 返回冷区循环。
- 同类：van Arkel–de Boer 法 [[Ti(s) + 2I2(g)]] ⇌ [[TiI4(g)]]（放热），粗 Ti 在较冷处生成 TiI₄，在约 1400 °C 的热钨丝上分解沉积高纯 Ti；卤钨灯中 W 也是这样被“送回”灯丝。
!! B3_04_CVT_examples_ZnS_Mond.png | 红箭头 = 被输运物质的气态形式的扩散方向；蓝虚线 = 输运剂回流
## 方向的物理意义（Le Chatelier）：吸热反应高温时 K 大 → 热端“溶解”多、冷端“析出” → 物质从热流向冷；放热反应相反。所以只要知道 ΔrH 的符号，就能判断晶体长在哪一端。

CVT 的用途：①生长高质量单晶（远低于熔点、缺陷少）；②提纯（只有能形成挥发性物种的组分被输运）；③合成新化合物。
** 写“步骤”时四步缺一不可：溶解（源）→ 扩散 → 沉积（汇）→ 输运剂回流。

@@ 5 | Is there a method to achieve a chemical transport of carbon (hint: think of an gas phase species with oxygen)? Search the relevant thermodynamic data in the internet. In which industrial process does this process occur?
?? 有没有办法实现碳的化学输运（提示：想一想含氧的气态物种）？查找相关热力学数据。这一过程出现在哪个工业过程中？
>> **可以，用 Boudouard 平衡：[[C(s) + CO2(g)]] ⇌ [[2CO(g)]]**（CO₂ 作输运剂，CO 为碳的气态载体）。

热力学数据（298 K，标准值）：
| 物质 | ΔfH° / kJ·mol⁻¹ | S° / J·mol⁻¹·K⁻¹ |
| C（石墨） | 0 | 5.7 |
| CO(g) | −110.5 | 197.7 |
| CO₂(g) | −393.5 | 213.8 |
- ΔrH° = 2(−110.5) − (−393.5) = **+172.5 kJ/mol**（吸热）
- ΔrS° = 2(197.7) − 213.8 − 5.7 = **+175.9 J/(mol·K)**
- ΔrG° = ΔrH° − TΔrS° = 0 时 **T ≈ 172 500 / 175.9 ≈ 981 K（≈ 708 °C）**，即在 700 °C 附近 K ≈ 1 → 满足 B3.3 的条件。
- 吸热 → **碳从热端输运到冷端**：热端 C + CO₂ → 2CO；冷端 2CO → C + CO₂（CO 歧化析出碳）。

**工业过程：高炉炼铁**——下部高温区 [[CO2 + C]] → [[2CO]] 不断再生还原剂 CO；上部较冷区（400–700 °C）CO 发生歧化 [[2CO]] → [[C + CO2]]，在炉料中析出碳（“积碳”）。（同一平衡也出现在合成气/重整催化剂积碳、CVD 制备碳纳米管中。）
!! B3_05_boudouard_carbon_transport.png | (a) ΔrG°(T)，约 981 K 时为零；(b) 1 bar 下平衡气体组成：高温以 CO 为主；(c) 碳由热端向冷端输运
## 为什么不用 [[C + O2]] → [[CO2]] 或 [[2C + O2]] → [[2CO]] 来输运？它们的 ΔrG° 都是很大的负值（K ≫ 1），反应不可逆、不存在“逆反应析出碳”，所以不能输运——违反 B3.3 的第二个条件。Boudouard 反应 ΔrS > 0（1 mol 气体变 2 mol），使得 ΔrG° 在中等温度穿过零，正好合适。

平衡组成（1 bar）：800 K 时 CO 约 9 %，981 K 约 62 %，1100 K 约 91 %——这就是高炉里“高温区以 CO 为主、低温区 CO 歧化”的原因。（另一种可能：[[C + 2H2]] ⇌ [[CH4]]，放热，碳会从冷端输运到热端。）
** 数据单位注意：ΔH 用 kJ、ΔS 用 J/K，算 T 时统一单位。

@@ 6 | Develop an idea to produce a TiO<sub>2</sub> Xerogel and describe the various steps?
?? 设计一种制备 TiO₂ 干凝胶（xerogel）的方案，并描述各个步骤。
>> **溶胶–凝胶法（sol–gel）**，前驱体用钛醇盐 Ti(OR)₄（如钛酸四异丙酯 Ti(OⁱPr)₄ 或钛酸四丁酯）：
- **① 配制前驱体溶液**：Ti(OⁱPr)₄ 溶于异丙醇；加**螯合剂**（乙酰丙酮或乙酸）和少量**酸催化剂**（HNO₃/HCl），减慢 Ti 醇盐过快的水解；
- **② 水解**：缓慢滴加定量水（水/醇溶液）：[[Ti(OR)4 + H2O]] → [[Ti(OR)3(OH) + ROH]] … → [[Ti(OH)4]]
- **③ 缩合 → 溶胶（sol）**：失水缩合 ≡Ti–OH + HO–Ti≡ → ≡Ti–O–Ti≡ + H₂O；失醇缩合 ≡Ti–OR + HO–Ti≡ → ≡Ti–O–Ti≡ + ROH，形成纳米胶体粒子；
- **④ 凝胶化（gelation）**：粒子继续交联，Ti–O–Ti 网络贯穿整个容器（凝胶点），孔中充满溶剂 → 湿凝胶；**老化**数小时到数天使网络增强；
- **⑤ 常压干燥**（如 60–100 °C 缓慢蒸发溶剂）：毛细管力使网络收缩塌陷 → **干凝胶 xerogel**（多孔、体积大幅收缩）；
- **⑥（可选）煅烧** 400–500 °C：除去残余有机物和 OH，无定形 → 锐钛矿 TiO₂（更高温度 → 金红石）。

总反应：[[Ti(OR)4 + 2H2O]] → [[TiO2 + 4ROH]]
!! B3_06_TiO2_xerogel_sol_gel.png | 上：前驱体与关键反应；下：溶胶 → 凝胶 → 干凝胶 → 煅烧的流程（右侧对比：超临界干燥得气凝胶）
## 各步的“为什么”：
- 为什么要控制水解？Ti 是四价、亲氧性强，Ti 醇盐遇水几秒钟就会直接沉淀出 TiO₂·nH₂O 粉末，得不到均匀的凝胶；螯合剂（acac）占据 Ti 的配位位置、酸使粒子带正电互相排斥，都能让缩合变慢变均匀。
- **xerogel vs aerogel**：区别只在干燥方式。常压蒸发时孔中存在气–液界面，毛细管压力 ΔP = 2γcosθ / r（孔越小压力越大）把网络压塌 → xerogel（比表面积仍较高但收缩、易开裂）；超临界干燥（如 CO₂ 超临界）没有气–液界面 → 网络保持 → aerogel（孔隙率 > 90 %）。
- 溶胶–凝胶的优点：低温、分子级均匀混合（易掺杂）、可做薄膜（浸涂/旋涂）、纤维、块体和粉末。TiO₂ 干凝胶可用作光催化剂、染料敏化太阳能电池的多孔电极。
** 必须写出“水解 + 缩合”两类反应和“溶胶 → 凝胶 → 干燥 → 干凝胶”顺序；能说出 xerogel 与 aerogel 的区别是加分点。
