Q01L1 尺寸与构象计算Mn / Mw / PDI

A polymer sample contains 2.0 mol of chains with M = 10 kg/mol and 3.0 mol of chains with M = 20 kg/mol. What is the polydispersity index (PDI) of this sample?

  • A1.00
  • B1.09✓ 正确答案
  • C1.25
  • D1.75

答案 B　·　解析

Mn = ΣniMi / Σni = [2(10)+3(20)] / 5 = 80/5 = 16 kg/mol

Mw = ΣniMi2 / ΣniMi = [2(100)+3(400)] / 80 = 1400/80 = 17.5 kg/mol

PDI = 17.5 / 16 = 1.09

陷阱：Mw 的分母是 ΣniMi（总质量），不是 Σni。误用 Σni 会得到 280。另外 Mw ≥ Mn 恒成立，算出 PDI < 1 一定错了。

Q02L1 尺寸与构象计算伸直长度 vs RMS 末端距

For a polyethylene chain with M = 280,000 g/mol, what is the ratio of its fully stretched-out (contour) length to its RMS end-to-end distance? Assume C–C bond length = 1.54 Å, tetrahedral bond angle 109.5°, and free rotation.

  • A10
  • B50
  • C100✓ 正确答案
  • D200

答案 C　·　解析

① 数键数：每个 CH2 单元 14 g/mol → n = 280,000 / 14 = 20,000 个 C–C 键

② 伸直长度：20,000 × 1.54 = 30,800 Å

③ RMS 末端距（固定键角、自由旋转）：

⟨h²⟩ = n l² · (1 + cos θ) / (1 − cos θ)

θ = 180° − 109.5° = 70.5°，cos 70.5° = 0.334 → 因子 = 1.334 / 0.666 = 2.00

⟨h²⟩ = 20,000 × 1.54² × 2 = 94,864 Å² → ⟨h²⟩1/2 = 308 Å

④ 30,800 / 308 = 100

本课最大的陷阱：公式里的 θ 是键角的补角，不是键角本身。若直接代 cos 109.5° = −0.334，因子变成 0.5，答案差 4 倍。课程发布的 Question 4 专门考这个，还加了 hint：“Is θ the bond angle?”

物理意义：无规线团比伸直链小两个数量级——高分子在溶液里是“球”不是“棍”。

Q03L1 尺寸与构象计算回转半径 Rg

An ideal polymer chain has a degree of polymerization N = 10,000 and a statistical segment length b = 5.0 Å. What is its radius of gyration Rg?

  • A50 Å
  • B204 Å✓ 正确答案
  • C500 Å
  • D1,250 Å

答案 B　·　解析

Rg² = N b² / 6 = 10,000 × 25 / 6 = 41,667 Å²

Rg = √41,667 = 204 Å

陷阱：① 忘记除以 6（得 500 Å，就是选项 C）；② 忘记开方。

必背换算：Rg² = ⟨h²⟩/6，即 ⟨h²⟩1/2 = √6 · Rg ≈ 2.45 Rg

顺带：把链密堆成半径 R₀ 的球，则恒有 Rg < R₀——Rg 是均方根距离，总有单体比它更远，不代表最大空间尺度。（课程 Question 5）

Q04L2 混合热力学计算理想混合熵

1.0 mol of ideal liquid A is mixed with 1.0 mol of ideal liquid B at 298 K. What is ΔSmix?

  • A5.76 J K⁻¹
  • B11.5 J K⁻¹✓ 正确答案
  • C17.3 J K⁻¹
  • D23.1 J K⁻¹

答案 B　·　解析

ΔSmix = −nR (xA ln xA + xB ln xB)

n 是总摩尔数 = 2.0 mol，xA = xB = 0.5：

ΔS = −2.0 × 8.314 × [2 × 0.5 ln 0.5] = −2.0 × 8.314 × (−0.693) = +11.5 J K⁻¹

陷阱：n 是总摩尔数（2 mol），不是每种 1 mol。用 n = 1 得 5.76（选项 A）。

理想体系 ΔHmix = 0（理想气体无相互作用；理想溶液 A-A、B-B、A-B 作用相同），所以 ΔGmix = −TΔS = −3,435 J，自发。理想混合完全由熵驱动；因 0 < x < 1，ΔS 恒正、ΔG 恒负。

Q05L2 混合热力学计算格子模型组合数 Ω

A lattice contains 10 sites occupied by 4 molecules of A and 6 molecules of B. What is the number of configurations Ω?

  • A24
  • B210✓ 正确答案
  • C5,040
  • D3,628,800

答案 B　·　解析

Ω = m! / (mA! mB!) = 10! / (4! · 6!) = 3,628,800 / 17,280 = 210

陷阱：选项 D 是 10!（忘了除），选项 C 是 7!。

为什么重要：这是统计热力学推混合熵的起点。由 S = k lnΩ 配合 Stirling 近似 ln m! ≈ m ln m − m，可得 S = −k(mA ln xA + mB ln xB)。

混合前纯物质只有一种排法，Ω = 1 → S = 0，所以 ΔSmix 就等于混合后的 S。换成摩尔量（NAvk = R）就回到热力学路线的同一个结果。（课程 Question 8 同型）

Q06L2 混合热力学计算χ 与混合焓

For a regular solution with interaction parameter χ = 1.2, an equimolar mixture (2.0 mol total) is prepared at 298 K. What is ΔHmix?

  • A372 J
  • B743 J
  • C1,487 J✓ 正确答案
  • D2,974 J

答案 C　·　解析

ΔHmix = xA xB χ n R T

= (0.5)(0.5)(1.2)(2.0)(8.314)(298)

分步：0.25 × 1.2 = 0.3；2.0 × 8.314 × 298 = 4,955 J；0.3 × 4,955 = 1,487 J

陷阱：n 仍是总摩尔数 2.0 mol（用 1.0 得选项 B）。

χ 是什么：χ = zΔw / kT，其中 Δw = wAB − wAA/2 − wBB/2 是交换能——把一对 A-A 和一对 B-B 换成两对 A-B 的能量代价，用热能 kT 归一化。

ΔGmix = nRT [ xAln xA + xBln xB + xAxBχ ]

课程 Question 9 问“油水为什么不互溶”，答案就是 xAxBχ 这个焓项为正，压过了恒负的熵项。焓项在 x = 0.5 时最大。

Q07L3 Flory-Huggins计算高分子混合熵

A polymer B with degree of polymerization N = 1000 is mixed with solvent A at φA = φB = 0.5. Compared with a small-molecule regular solution at the same volume fractions, the entropy of mixing of this polymer solution is approximately:

  • Athe same
  • Bone half✓ 正确答案
  • Cone thousandth
  • Done thousand times larger

答案 B　·　解析

ΔSmix = −nR [ φA ln φA + (φB/N) ln φB ]

小分子（N = 1）：−[0.5 ln0.5 + 0.5 ln0.5] = 0.693 nR

高分子（N = 1000）：−[0.5 ln0.5 + (0.5/1000) ln0.5] = −[−0.3466 − 0.000347] = 0.347 nR

比值 = 0.347 / 0.693 = 0.50

最重要的误解澄清：很多人以为除以 N 会让熵变成 1/N（选项 C）。错——只有高分子那一项被 N 除，溶剂项原封不动。所以 φ = 0.5 时 N 再大也只减到约一半（N→∞ 的极限是 0.5，不是 0）。

物理图像：N 个单体被共价键“绑”在一起，可排布方式大幅减少。课程 Question 10 的直观例子：8 格放 2 个黑球，不相连 28 种，连起来只有 10 种。

推论（课程 Question 11）：ΔS 更小 → −TΔS 这个有利项更弱 → 高分子溶解不如小分子自发。
而焓项 φAφBχnRT 不除 N，因为焓只取决于溶剂-单体的局部接触。

Q08L3 Flory-Huggins计算体积分数

A Flory-Huggins lattice contains 800 solvent molecules and 2 polymer chains, each with a degree of polymerization N = 100. What is the volume fraction of polymer φB?

  • A0.002
  • B0.2✓ 正确答案
  • C0.25
  • D0.8

答案 B　·　解析

φB = N mB / (mA + N mB) = (100 × 2) / (800 + 200) = 200 / 1000 = 0.2

相应 φA = 0.8，总格点数 m = mA + NmB = 1000。

陷阱：选项 A 是按摩尔分数算的 2/(800+2) ≈ 0.0025。Flory-Huggins 用体积分数，不用摩尔分数——一条链占 N 个格点，这正是“高分子体积大”在模型里的体现。

Q09L3 Flory-Huggins理解N 对相图的影响

According to Flory-Huggins theory, as the degree of polymerization N of the dissolved polymer increases, the phase diagram of the polymer solution (UCST type) changes in which way?

  • ACritical temperature decreases; phase diagram shifts to higher polymer volume fraction
  • BCritical temperature increases; phase diagram shifts to lower polymer volume fraction✓ 正确答案
  • CCritical temperature increases; phase diagram shifts to higher polymer volume fraction
  • DThe phase diagram is unaffected by N

答案 B　·　解析

讲义 Lecture 4「Phase Diagram of Polymer Solutions」页的两条 general conclusions：

① Critical point increases as N increases
② Phase diagram shifts towards smaller φB as N increases（means only dilute samples can dissolve）

为什么：N ↑ → 混合熵 ↓ → −TΔS 这个有利项变弱 → 需要更高的温度才能压过焓项 → Tc 升高，单相区缩小。

实际含义（常出概念题）：分子量越高越难溶；而且只有稀溶液才溶得了，想溶浓一点就分相。另外高分子相图不对称（因为 φB/N 这一项），不像小分子那样左右对称。

Q10L4 相行为理解spinodal 的数学判据

The spinodal boundary at a given temperature is located mathematically by solving:

  • AdΔGm/dxA = 0
  • Bd²ΔGm/dxA² = 0✓ 正确答案
  • Cd³ΔGm/dxA³ = 0
  • DDrawing a common tangent to the ΔG curve

答案 B　·　解析

三个判据必须分清楚：

目标方法物理含义
Binodal 共存曲线公切线的两个切点（选项 D）分相后能达到的最低能量组成
Spinodal 稳定极限d²ΔG/dx² = 0（拐点）曲率由凹向上转为凹向下
临界点 Tcd³ΔG/dx³ = 0两个拐点合并、“鼓包”刚出现

为什么 spinodal 是拐点：曲线凹向上处，任何微小组成涨落都升高 G → 涨落自动退回 → 溶液亚稳；曲线凹向下处，微小涨落降低 G → 无势垒自发分相。两者的分界正是曲率变号的拐点。

所以 binodal 与 spinodal 之间是亚稳区：热力学上分相有利，但要一次足够大的涨落才能启动。

Q11L4 相行为理解两种分相机理

Which of the following statements comparing spinodal decomposition (SD) with nucleation and growth (N&G) is FALSE?

  • ASD has no activation barrier, while N&G does
  • BSD occurs uniformly throughout the entire volume, while N&G occurs sporadically
  • CSD and N&G give different final phase compositions✓ 正确答案
  • DN&G occurs when the mixture lies outside the spinodal but inside the binodal

答案 C　·　解析

选 C，因为它是错误陈述。讲义 Lecture 4 最后一页的对比表：

Spinodal DecompositionNucleation & Growth
发生位置spinodal 内spinodal 外、binodal 内（亚稳区）
空间分布整个体积均匀零星散发
活化势垒无有
最终组成binodal 组成binodal 组成

关键：两种机理的终态组成完全相同，都由 binodal 点决定。区别只在路径和形貌：SD 组成在整个体积内连续演化，固体中给出互穿网络；N&G 先偶然成核，再靠扩散（组成梯度驱动）长大，给出分散的核/液滴。

课程 Question 15、16 分别问这两种机理的终态，答案都是 “2 phases comprising a and b”（binodal 组成）。

Q12L4 相行为理解binodal 之外不分相

A mixture of A and B has a Gibbs energy of mixing curve with a local maximum. Compounds A and B are mixed at a composition xA that lies outside the two binodal points, and ΔGmix at this composition is negative. What is the resulting state?

  • A1 phase with composition xA✓ 正确答案
  • B2 phases at the spinodal compositions a and b
  • C2 phases at the binodal compositions xA′ and xA″
  • D2 phases of pure A and pure B

答案 A　·　解析

判据不是“ΔGmix 是不是负的”，而是“能不能通过分相得到更低的能量”。

在两个 binodal 点之外，ΔG 曲线凹向上。对凹向上的曲线，无论怎么选 xA′ 和 xA″，两相的加权平均 Gibbs 能（连接两点的直线在 xA 处的高度）总是高于单相曲线上的点 → 分相反而升高能量 → 保持单相。（课程 Question 17）

三种情况一起记：

组成位置结果
binodal 之外单相（本题）
binodal 与 spinodal 之间亚稳单相，需成核-生长 → 终态 binodal 组成
spinodal 之内无势垒自发 SD → 终态仍是 binodal 组成

最容易错的一点（课程 Question 13 专门考）：ΔGmix < 0 不代表不分相。它只说明“混合比完全不混合好”，但分成两个 binodal 组成可以达到更低的能量。

Q13L4 相行为理解LCST

A polymer solution exhibits a lower critical solution temperature (LCST), i.e. it phase separates upon heating. Using the empirical relation χ = α/T + β, this behaviour requires:

  • Aα positive and β negative, so that χ decreases with temperature
  • Bα negative and β positive, so that χ increases with temperature✓ 正确答案
  • Cα = 0, so that χ is temperature-independent
  • Dβ = 0, so that χ = α/T

答案 B　·　解析

理论上：χ = zΔw/kT，温度越高 χ 越小 → 焓的不利影响越弱 → 高温互溶。这给出的是常见的 UCST。

但经验上 χ = α/T + β，α、β 可正可负。当 α 为负、β 为正时，T 升高使 α/T 这个负项绝对值变小 → χ 整体变得更正 → 焓项更不利 → 高温反而分相 → LCST。

经典例子（讲义点名）：聚环氧乙烷 PEO / 水。机理是靠氢键溶解，而氢键在高温下变弱。

记忆：UCST 常见，“升温溶解”，符合直觉；LCST 少见（讲义标题写的就是 “Less Usual Case”），“升温分相”，通常涉及氢键或特异性相互作用。

Q14L5 渗透压与粘度计算渗透压

A dilute polymer solution of concentration 5.0 g/L has a molar mass of 50,000 g/mol. At 298 K, ignoring virial terms, what height of aqueous solution column would this osmotic pressure support? (ρ = 1000 kg/m³, g = 9.81 m/s²)

  • A0.25 cm
  • B2.5 cm✓ 正确答案
  • C25 cm
  • D250 cm

答案 B　·　解析

① 单位换算（关键）：c 必须是 g/m³ 才能得到 Pa。
c = 5.0 g/L = 5,000 g/m³

② 渗透压：Π = RT·c/M = 8.314 × 298 × (5,000 / 50,000) = 8.314 × 298 × 0.1 = 248 Pa

③ 液柱高度：h = Π / (ρg) = 248 / 9,810 = 0.0253 m = 2.5 cm

最大的坑是单位。若直接代 c = 5 g/L，得 0.248 Pa，差 1000 倍。记住：SI 制下 c 用 g/m³、M 用 g/mol，Π 出来就是 Pa。

为什么渗透压法好用：248 Pa 很小，但换成液柱是 2.5 cm——肉眼可读，精度高。
渗透压测 Mn：第一项 RTc/M 只与分子数目有关（依数性），与种类无关。课程 Question 18 就考这点：等浓度葡萄糖和蔗糖溶液渗透压基本相同。

Q17L6 光散射计算Rayleigh λ⁻⁴

According to Rayleigh’s equation, what is the ratio of scattered intensity for blue light (450 nm) to that for red light (650 nm) by the same small particle at the same angle?

  • A1.4
  • B2.1
  • C4.4✓ 正确答案
  • D8.7

答案 C　·　解析

Iθ/I0 = 8π⁴α²(1 + cos²θ) / (λ⁴ r²)　→　I ∝ λ⁻⁴

I450 / I650 = (650/450)⁴ = (1.444)⁴ = 4.35

陷阱：是 λ⁻⁴，比值要四次方。一次方得 1.44（选项 A），二次方得 2.09（选项 B）——错误选项就是这么设计的。还要注意别把分子分母颠倒：波长短的散射强，蓝光在分子上。

天空为什么是蓝的（课程 Question 22，选项很刁）：
✅ 蓝光波长短，被空气分子散射得强得多；我们看天空是朝偏离太阳的方向看，看到的是被散射的蓝光。
❌ “其他颜色被水蒸气吸收” / “蓝光是海水反射的” / “非蓝光被散射掉了，剩下蓝光”

(1 + cos²θ) 说明小粒子散射前后对称。但粒子 > λ/20 时，同一粒子不同部位的散射光相消干涉，强度净减少，且前向 > 后向；唯一不受影响的角度是 θ = 0°。正是这个角度依赖让静态光散射能给出 Rg。

Q18L6 光散射计算Stokes-Einstein

In a DLS experiment, the tracer diffusion coefficient of a polymer in water is Dt = 2.0×10⁻¹¹ m²/s at 298 K. The solvent viscosity is 0.89 mPa·s. What is the hydrodynamic radius Rh?

  • A1.2 nm
  • B12 nm✓ 正确答案
  • C120 nm
  • D1.2 μm

答案 B　·　解析

Dt = kT / (6π ηs Rh)　→　Rh = kT / (6π ηs Dt)

分子：kT = 1.381×10⁻²³ × 298 = 4.115×10⁻²¹ J
分母：6π × 0.89×10⁻³ × 2.0×10⁻¹¹ = 3.355×10⁻¹³

Rh = 4.115×10⁻²¹ / 3.355×10⁻¹³ = 1.23×10⁻⁸ m = 12.3 nm

单位：0.89 mPa·s = 0.89×10⁻³ Pa·s。漏掉 10⁻³ 差 1000 倍。

DLS 的整条逻辑链：① 布朗运动 → 干涉明暗斑移动 → 强度随时间涨落；② 小粒子扩散快 → 涨落快（课程 Question 24）；③ 用时间自相关函数 C(t′) 提取衰减速率——t′=0 时自乘最大，t′→∞ 时完全不相关、平均为 0，结果是指数衰减 C ∝ e−2q²Dmt′，D 越大衰减越快；④ 外推零浓度得 Dt，由 Stokes-Einstein 得 Rh。

三种“半径”别混：Rg ← 静态光散射；Rh ← 动态光散射；R₀ ← 密堆积球，概念上 Rg < R₀。

Q19L7 SEC 与质谱理解SEC 洗脱顺序

In size exclusion chromatography (SEC), which molecules elute first, and why?

  • AThe smallest, because they diffuse fastest through the column
  • BThe largest, because they are excluded from the pores of the stationary phase✓ 正确答案
  • CThe smallest, because they are retained least strongly by the stationary phase
  • DThe most polar, because they interact least with the gel

答案 B　·　解析

SEC（也叫 GPC）用多孔凝胶作固定相：大分子进不了孔 → 只走孔外体积 → 路径短 → VR 小、先出；小分子能进孔 → 被滞留 → 后出。

两个固有问题（讲义明确列出）：
① SEC 依据是尺寸而非 M → 标样的化学组成和结构必须与未知样相同，否则不准；
② 比孔还大的分子全部一起出来，VR 完全没有区分度。

四种检测器：示差折光（∝浓度）· UV-Vis（Beer-Lambert，需发色团）· 光散射（配合前两者给 Mw，可不需标样）· 粘度计（同上）。

Q20L7 SEC 与质谱计算通用校准

Universal calibration is applied to an SEC column. A polystyrene standard (ks = 8×10⁻⁵, as = 0.5) with Ms = 50,000 g/mol elutes at a certain retention volume. An unknown polymer (kx = 1×10⁻⁵, ax = 0.5) elutes at the same retention volume. What is Mx?

  • A50,000 g/mol
  • B100,000 g/mol
  • C200,000 g/mol✓ 正确答案
  • D400,000 g/mol

答案 C　·　解析

核心思想：流体力学体积 Vh 相同的高分子有相同的 VR（SEC 按尺寸分离）。

由 [η] = (5/2)NAvVh/M 和 [η] = kMa 得 Vh ∝ k Ma+1，同一 VR ⇒

ks Msas+1 = kx Mxax+1

代入（as = ax = 0.5，指数都是 1.5）：

8×10⁻⁵ × (50,000)1.5 = 1×10⁻⁵ × Mx1.5
Mx1.5 = 8 × (50,000)1.5 → Mx = 82/3 × 50,000 = 4 × 50,000 = 200,000

陷阱：不能直接按 k 的比值 8 倍去乘 M（得 400,000，选项 D）。指数 1/(a+1) = 2/3 必须用上。82/3 = (∛8)² = 2² = 4。

为什么需要它：直接用 PS 标样曲线读未知高分子，会因“同样 M 但尺寸不同”而系统偏差。通用校准用 Mark-Houwink 常数修正 y 轴，前提是两种高分子的 k、a 都已知。

  • B40 μs✓ 正确答案
  • C80 μs
  • D320 μs

Q23L8 玻璃态理解Tg 是二阶转变

  • ATg is a first-order transition, showing a discontinuity in volume
  • BTg is a second-order transition: volume is continuous but its temperature derivative jumps✓ 正确答案
  • CFaster cooling gives a lower Tg because there is less time to pack
  • DTg is a material constant, independent of thermal history

答案 B　·　解析

由 (∂G/∂p)T = V、(∂G/∂T)p = −S，而 α = (1/V)(∂V/∂T)p、Cp = (∂H/∂T)p：

熔融 Tm玻璃化 Tg
阶数一阶二阶
跳变在G 的一阶导（V、H）G 的二阶导（α、Cp）
V–T 曲线跳变连续，只有斜率变 → Tg 需外推交点

Q24L8 玻璃态计算Flory-Fox 方程

Polystyrene obeys the Flory-Fox equation with Tg(M∞) = 100 °C, and a sample with Mn = 20,000 g/mol has Tg = 90 °C. What is the Tg of a sample with Mn = 10,000 g/mol?

  • A45 °C
  • B80 °C✓ 正确答案
  • C85 °C
  • D95 °C

答案 B　·　解析

Tg(Mn) = Tg(M∞) − K / Mn

① 求 K：90 = 100 − K/20,000 → K/20,000 = 10 → K = 2×10⁵

② 代入 Mn = 10,000：Tg = 100 − 2×10⁵/10⁴ = 100 − 20 = 80 °C

快捷理解：Mn 减半 → K/Mn 加倍 → 偏离量从 10 °C 变 20 °C。

陷阱：选项 D 把关系当成正比例；选项 A 把 Tg 也减半了。

物理原因：链端的自由体积比链中间大。分子量越低 → 链端占比越高 → 链段更易运动 → Tg 越低。同理低分子量增塑剂降低 Tg，交联升高 Tg。

影响 Tg 的因素汇总：主链柔性高 ↓ · 刚性芳环主链 ↑（PEEK 143 °C）· 侧基大且刚性（苯基、酯基）↑ · 极性作用（氯、腈、酯）↑ · 分子量 ↑ · 增塑剂 ↓ · 交联 ↑

Q25L8 玻璃态计算Fox 方程

A miscible blend contains 80 wt% of polymer A (Tg = 100 °C) and 20 wt% of a plasticizer B (Tg = −50 °C). Using the Fox equation, estimate the Tg of the blend.

  • A70 °C
  • B56 °C✓ 正确答案
  • C40 °C
  • D20 °C

答案 B　·　解析

1 / Tg = wA/Tg(A) + wB/Tg(B)

① 换算成绝对温度（关键）：Tg(A) = 373 K，Tg(B) = 223 K

② 1/Tg = 0.8/373 + 0.2/223 = 0.002145 + 0.000897 = 0.003042

Tg = 1/0.003042 = 328.8 K = 55.6 °C ≈ 56 °C

两个陷阱，选项 A 同时踩中：
① Fox 方程必须用绝对温度 K。用摄氏度算完全错，而且 −50 °C 会让分母出负数。
② Fox 不是线性加权。线性加权给 0.8(100) + 0.2(−50) = 70 °C，正是选项 A。Fox 是倒数的加权平均，结果总是低于线性值。

物理含义：可混溶共混物只有一个 Tg，介于两组分之间——这本身就是判断两种高分子是否互溶的实验判据（不互溶会看到两个 Tg）。加 20% 增塑剂把 Tg 从 100 °C 拉到 56 °C，这就是 PVC 从硬管变软管的原理。

Q26L9 力学性质计算杨氏模量

A polymer bar with a cross-sectional area of 2.0 mm² and an original length of 50 mm elongates by 1.0 mm under a 100 N load, within the linear elastic region. What is its Young’s modulus?

  • A0.5 GPa
  • B1.0 GPa
  • C2.5 GPa✓ 正确答案
  • D5.0 GPa

答案 C　·　解析

应力：σt = f/A = 100 N / (2.0×10⁻⁶ m²) = 5.0×10⁷ Pa = 50 MPa

应变：ε = ΔL/L₀ = 1.0/50 = 0.020

模量：E = σ/ε = 50 MPa / 0.020 = 2500 MPa = 2.5 GPa

单位换算：1 mm² = 10⁻⁶ m²（不是 10⁻³）。这是最常见的失分点。应变无量纲，不用换算。

三类应力-应变行为：

类型特征例子
A 脆性E 高，近似线性直到断裂，无屈服点PS、PMMA
B 韧性升到屈服点 → 塑性形变 → 应变软化 → 断裂前 E 回升（应变硬化）PP、PE
C 弹性体E 极低，无屈服点，断裂应变 500–1000%天然橡胶

两个强度别混：抗拉强度 = 断裂点的最大应力；屈服强度 = 开始不可恢复形变时的应力。
三种形变机理：Crazing 银纹（裂纹扩展，原纤间 10–20 nm 微孔洞，垂直于应力扩展，散射光发白，能起银纹反而强韧）· Shear banding（与应力成 ~45°）· Necking 细颈（屈服点之后立即发生）。

Q27L10 弹性体与结晶理解熵弹性

When a crosslinked rubber is held at a fixed extension and its temperature is raised, the tensile force f is observed to increase. What does this tell us about the molecular origin of rubber elasticity?

  • AThe enthalpy increases strongly with extension, so the restoring force is enthalpic
  • BThe entropy decreases with extension, so the restoring force is entropic✓ 正确答案
  • CThe entropy increases with extension, so stretching is spontaneous
  • DThe rubber is below its Tg at this temperature

答案 B　·　解析

由 dG = Vdp − SdT + f dL 及二阶偏导可交换（Maxwell 关系）：

(∂f/∂T)p,L = − (∂S/∂L)p,T

实验观察：固定伸长率（讲义用 350%），f 随 T 升高 → 左边斜率为正 → (∂S/∂L) 为负 → 拉伸使熵下降。

为什么熵下降：伸展的构象是有序的，可及构象数远少于无规线团 → 构象熵减少。

再看截距：由 G = H − TS 得 f = (∂H/∂L)p,T − T(∂S/∂L)p,T。f–T 直线的 y 轴截距 = (∂H/∂L)，实测接近零 → 拉伸几乎不把能量以焓储存 → 应力几乎全部用于降低熵。

橡胶弹性是熵弹性，不是键的拉伸

两个必须一起记的推论：① f–T 曲线在低温处的反转点 = 玻璃化转变（此时已不是弹性体，选项 D 的干扰就在这）；② 绝热拉伸橡皮筋会升温：CV,pΔT = AEL²/(2L₀)，弹性功无处可去全变内能。
弹性体四条件：温度高于 Tg · 结晶度可忽略 · 必须交联 · 形变完全可恢复。交联靠硫化（硫加热交联 cis-1,4-聚异戊二烯，机理未完全清楚，证据指向离子型反应）。

An X-ray diffraction pattern of polyethylene recorded with Cu Kα radiation (λ = 1.54 Å) shows a first-order (n = 1) reflection at a diffraction angle 2θ = 21.5°. What is the spacing between the corresponding crystal planes?

  • A2.06 Å
  • B4.13 Å✓ 正确答案
  • C8.26 Å
  • D0.41 Å

2 D sin θ = n λ

① 2θ 除以 2：θ = 21.5° / 2 = 10.75°，sin(10.75°) = 0.1865

② D = nλ / (2 sin θ) = 1.54 / (2 × 0.1865) = 1.54 / 0.373 = 4.13 Å

Q29L10 弹性体与结晶理解Tm 的依赖因素

Which of the following changes would lower the melting temperature Tm of a semicrystalline polymer?

  • AIncreasing the lamellar thickness
  • BIncreasing the number-average molecular weight
  • CDecreasing the lamellar thickness✓ 正确答案
  • DIncreasing the enthalpy of fusion per unit volume

答案 C　·　解析

Tm / Tm∞ = 1 − (2γ / ΔHVb) · (1/l + 1/r)

（l 片晶厚度，r 半径，γ 单位面积表面能）

l 或 r 减小 → 1/l + 1/r 增大 → 右边减小 → Tm 降低。物理原因：晶体越小，表面能占比越大，而熔融要“回收”这部分表面能。

逐项：A 升高 Tm（更厚的片晶表面占比小）· B 升高（见下）· C 降低 ✓ · D 升高（分母变大 → 修正项变小）

分子量的影响（另一条独立推导）：链端相当于杂质，造成熔点降低（凝固点降低的依数性）。每条链 2 个链端，链端摩尔分数 xB = 2M₀/Mn，故 Mn 越低 → 链端分数越高 → Tm 越低。

结晶机理：高分子按成核-生长结晶。片晶厚度由热力学 + 动力学共同决定——热力学上薄片晶 Tm 低，只有低温才允许；动力学上薄片晶生长更快 → 低温下薄片晶占主导，更薄的片晶刚被允许时生长速率出现突变。
能否结晶：立构规整（isotactic、syndiotactic）才能结晶，无规（atactic）不能；例外是带小极性侧基的（PVA、聚氟乙烯）。结晶的好处：强度提高、抗降解、阻隔性好。
四种形貌：球晶 · hedrite · 枝晶（深过冷）· shish kebab 串晶（流动下结晶）。

Q30综合 跨讲综合综合折射率不均 → 散射

A glassy polymer such as PMMA is optically transparent, whereas a semicrystalline polymer such as high-density polyethylene appears hazy or opaque. What is the reason?

  • ACrystalline regions absorb visible light while amorphous regions do not
  • BThe refractive index difference between crystallites and amorphous regions causes light scattering✓ 正确答案
  • CGlassy polymers have a lower refractive index than crystalline ones
  • DCrystalline polymers have a higher Tg, which increases absorption

答案 B　·　解析

讲义 Lecture 8 原文：玻璃态高分子光学透明——链无规堆砌（像液体），折射率处处均一，因此没有散射；半结晶高分子——晶区与非晶区折射率不同 → 光散射 → 发雾/不透明。

关键词是“散射”不是“吸收”（排除 A、D）。两种状态化学结构相同、电子跃迁能级相同，可见光吸收本来就差不多；差别完全来自微观结构的光学均一性。

这题串起三讲：
① Lecture 6：光散射的根源是折射率不均匀。讲义说 dn/dc 越大散射越强，同一道理——折射率差别越大散射越强（课程 Question 23）。
② Lecture 8：玻璃态 vs 半结晶态的光学性质。
③ Lecture 9：crazing 银纹也是同一机理——原纤间 10–20 nm 微孔洞与高分子折射率差极大 → 强散射 → 应力发白。把塑料尺弯到发白就是在看银纹。

顺带的加工性对比：玻璃态高分子更易从熔体加工（冷下来就得到了）；结晶高分子需精细控制结晶动力学；结晶高分子通常力学更强，但高 Tg 的玻璃态对很多应用已够用。
