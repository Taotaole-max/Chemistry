Lecture 1 · Polymer Size and Conformations

高分子的分类（按热机械性质）

类别 特征 例子
Thermoplastics 热塑性 受热软化/熔融，可反复加工（模压、挤出） PS, PP
Thermosets 热固性 高度交联，链运动受限；耐热耐溶剂但不能热加工 环氧树脂、酚醛树脂
Elastomers 弹性体 轻度交联的软橡胶，大形变可恢复 天然橡胶、硅橡胶

平均分子量

Mn = Σi niMiΣi ni = ∫nM dM∫n dM   Mw = Σi niMi2Σi niMi = ∫nM2 dM∫nM dM
PDI=MwMn
  • Mn 数均：按分子个数平均，每条链权重相同
  • Mw 重均：按质量加权，大分子贡献更大，所以恒有 Mw ≥ Mn
  • PDI = 1 单分散；1 < PDI < 1.5 窄分布；PDI > 2 宽分布

⚠️ 易错：Mw 的分母是 Σn_iM_i（总质量），不是 Σn_i。

末端距（end-to-end distance）

链是各向同性的，所以平均矢量 ⟨h⟩ = 0，必须求均方根（RMS）。

三种模型，全都 ∝ nl²，只差一个前置因子：

模型 ⟨h²⟩
Freely-jointed chain 自由连接链 nl2
固定键角、自由旋转 nl21+cosθ1-cosθ
固定键角、固定旋转角 φ nl21+cosθ1-cosθ·1+cosφ1-cosφ

统一写成：

⟨h2⟩ =  C∞ n l2  =  N b2

  • C∞ 特征比（characteristic ratio），把局部化学约束全部打包
  • b 统计链段长度（statistical segment length），"有效"单元长度
  • N 聚合度

⚠️⚠️ 最大的坑：公式里的 θ 是键角的补角，不是键角本身。 sp³ 键角 109.5° → θ = 180 − 109.5 = 70.5°，此时因子 (1+cos70.5)/(1−cos70.5) ≈ 2.00。 这是过去考题 Question 4 明确设的陷阱。

回转半径 Rg

末端距只看首尾两个单体，Rg 看所有单体到质心的均方根距离，而且Rg 可以被光散射直接测量。

Rg = (1NΣi=1Nsi2)1/2,   Rg2 = 12N2ΣiΣj ⟨rij2⟩

理想链结果：

Rg2 = Nb26 = ⟨h2⟩6  ⇒  ⟨h2⟩1/2 = √6 Rg≈2.45 Rg

Rg 恒小于把高分子塞进的那个球的半径 R₀——因为 Rg 是均方根距离，总有一部分单体比 Rg 更远，Rg 不代表最大空间尺度。（过去考题 Question 5）

情形 ν 说明

Lecture 2 · Thermodynamics of Mixtures

基本热力学骨架

dU=dq+dw+dwadd, dqrev=TdS, dwrev = -p dV

基本方程：dU=TdS-p dV+dwadd

焓 H=U+pV ⇒dH=dU+p dV+V dp；恒压下 dH = dq_p

Gibbs 能 G=H-TS ⇒dG=dH-TdS-SdT

自发性判据（Clausius 不等式出发）：

dGT,p=dH-TdS≤0

恒温恒压下 dG = dw_add，即 dG 是系统能做的最大非膨胀功 → 所以叫 "free energy"。

化学势 = 偏摩尔 Gibbs 能：

dG=V dp-S dT+μA dnA+μB dnB+⋯,  G=μA nA+μB nB

两个常用偏导：

(∂G∂p)T,n=V,  (∂G∂T)p,n = -S

气体：G 随压力变化

G=G°+nRTlnp  ⇒  μ=μ°+RTlnp

液体：Raoult 定律

液气平衡 → 化学势相等。纯液体 μ_A 对应蒸气压 p_A，混合后 μ_A 对应 p_A：

μA-μA*=RTlnpApA*,  Raoult: pApA*=xA
μA=μA*+RTlnxA

因为 0 < x_A < 1，ln x_A < 0，所以不纯液体的化学势总是低于纯液体。（过去考题 Question 7） 这是渗透压、凝固点降低、沸点升高的共同源头。

混合的 ΔG、ΔS、ΔH（理想）

气体和理想液体的结果完全相同：

ΔGmix=nRT(xAlnxA+xBlnxB)
ΔSmix = -(∂ΔGmix∂T)p,n = -nR(xAlnxA+xBlnxB)
ΔHmix=ΔG+TΔS=0
  • ΔG_mix 恒为负 → 理想混合总是自发
  • ΔS_mix 恒为正
  • 理想体系混合完全由熵驱动（理想气体无相互作用；理想溶液 A-A、B-B、A-B 作用相同）

统计热力学导出同一个结果

S=klnΩ,  Ω=m!mA! mB!

用 Stirling 近似 ln m! ≈ m ln m − m，可得 S = −k(m_A ln x_A + m_B ln x_B)。 混合前 Ω = 1 → S = 0，所以 ΔS_mix 就等于混合后的 S。换成摩尔量（N_Av·k = R）即回到上式。

非理想（regular solution）：交换能与 χ

格子模型，z 个近邻，相互作用能 w_AA、w_BB、w_AB：

Δw  =  wAB-wAA2-wBB2 (exchange energy 交换能)
χ=zΔwkT (interaction parameter 相互作用参数)

χ 就是"每分子交换能除以热能 kT"。

ΔHmix=xAxB χ  nRT
ΔGmix=nRT[xAlnxA+xBlnxB+xAxBχ]
  • 前两项是熵项，恒负，永远有利于混合
  • x_A x_B χ 是焓项，χ > 0 时为正，不利于混合——油水不互溶就是它。（过去考题 Question 9）
  • χ 项在 x = 0.5 时最大

Lecture 3 · Flory-Huggins 高分子溶液理论

设定

格子模型：m_A 个溶剂分子，m_B 条链，每条链聚合度 N。

m=mA+NmB,  φA = mAmA+NmB,  φB = NmBmA+NmB

高分子体系用体积分数 φ，不用摩尔分数 x。

推导要点（考推导思路，不一定考代数）

放第 i+1 条链时： - 第 1 个单体：可选空位 = m − iN - 第 2 个单体：必须放在近邻空位 → z·(m−iN)/m - 第 3 个及以后：少一个被占的近邻 → (z−1)·(m−iN)/m

总数 ≈ (z-1m)N-1(m-iN)N，对所有链连乘再除以 m_B!（链彼此全同）。

代入 S = k lnΩ，配合 Stirling 近似，最后：

ΔSmix = -nR[φAlnφA+φBNlnφB]
ΔHmix=φAφB χ  nRT
ΔGmix=nRT[φAlnφA+φBNlnφB+φAφBχ]

核心物理

  • 只有高分子那一项被 N 除，溶剂项不变。原因：N 个单体被"绑"在一起，可排布方式大幅减少。（过去考题 Question 10 用"黑球连起来"直观演示：8 格放 2 球，不连 = 28 种，连起来 = 10 种）
  • 因此 ΔS_mix 更小 → 溶解不那么自发。（过去考题 Question 11）
  • 焓项不除 N：焓只取决于溶剂-单体的局部接触，单体连不连成链无所谓。
  • N → ∞ 时高分子项趋于 0，只剩溶剂项。

⚠️ 常见误解：以为 ΔS 变成 1/N。实际在 φ = 0.5、N 很大时只减到约 一半（因为溶剂那项原封不动）。

Lecture 4 · 相行为

定义

Phase 相：化学组成和物理状态处处均一的那部分物质。

术语 含义
Binodal（共存曲线） 其下方分相在热力学上有利，但溶液可能停在亚稳态
Spinodal（稳定极限） 其下方分相自发无势垒
Critical point T_c 此温度以上，任何组成都是单相

为什么低温会出现"局部极大"

ΔGmixRT = ΔHmixRT-ΔSmixR
  • 高温：χ = zΔw/kT 小，熵占主导 → ΔG 曲线全程凹向上 → 单相
  • 低温：焓项相对变大 → ΔG 曲线中间鼓起一个局部极大 → 可能分相

判据（必背）

目标 方法
是否分相 ΔG 曲线凹向下就分相；凹向上就不分
Binodal 点 对 ΔG 曲线画公切线，两个切点即 binodal
Spinodal 点 拐点：d2ΔGmdxA2=0
临界点 T_c 两个拐点合并：d3ΔGmdxA3=0

⚠️ 关键理解：ΔG_mix < 0 不代表不分相。ΔG_mix<0 只说明"混合比不混合好"，但通过分相可能达到更低的能量。（过去考题 Question 13） 反过来，落在两个 binodal 点之外的组成不分相。（过去考题 Question 17）

两种分相机理

Spinodal Decomposition Nucleation and Growth
发生区域 spinodal 内 binodal 内、spinodal 外（亚稳区）
空间分布 整个体积均匀发生 零星散发发生
活化势垒 无 有（需要一次足够大的涨落）
微观机理 任何微小组成涨落都降低 G 小涨落升高 G，会退回去；只有大涨落越过切线才成核，之后靠扩散长大
形貌 互穿网络（interpenetrating network） 分散的核长大
最终组成 binodal 组成 binodal 组成（两者相同！）

⚠️ 两种机理终态组成都由 binodal 决定，区别在路径和形貌。（过去考题 Question 15、16）

高分子相图的特点

由 Flory-Huggins： - N 增大 → 临界点升高（单相区缩小，越难溶） - 相图向更小的 φ_B 移动 → 只有稀溶液才能溶 - 相图不对称（因为 φ_B/N 这一项）

UCST vs LCST

  • UCST（常见）：χ = zΔw/kT，温度升高 χ 减小 → 高温互溶
  • LCST（少见）：经验式
    χ=αT+β
    当 α 为负、β 为正时，升温使 χ 更正 → 高温反而分相。 例：聚环氧乙烷（PEO）/ 水，因为氢键在高温下变弱。

Lecture 5 · 渗透压与粘度法

渗透压 Π

来源：溶液侧化学势低（μ_A = μ_A + RT ln x_A < μ_A），溶剂想过膜稀释它。 液面升高产生压力，抬高溶液侧化学势直到两侧相等：

μA(p°+Π)=μA(p°)+VmΠ,  VmΠ=-RTlnxA

用 Taylor 展开 ln(1−x_B) ≈ −x_B − x_B²/2 − … 得 virial 展开：

Π=RT[cM+Bc2+B3c3+⋯]

六条结论（讲义原文）： 1. 第一项只与分子数目有关，与种类无关 → 依数性（colligative property） 2. 二、三项来自溶质-溶质相互作用（浓度升高才显著） 3. 良溶剂：高分子-溶剂作用有利，溶剂更想过膜 → B > 0 4. 不良溶剂：溶质-溶质作用有利 → B < 0 5. B = 0 的溶剂叫 θ 溶剂（此时链呈理想链行为，Rg ∝ N^1/2） 6. 多分散体系测到的 M 是 Mn（数均）

实验做法：画 Π/RT vs c，取低浓度处斜率 = 1/M。（过去考题 Question 19）

Vapour-Phase Osmometry (VPO)：密闭腔内两个热敏电阻，一滴溶液一滴纯溶剂。 溶液化学势低 → 溶剂蒸气在溶液上冷凝 → 溶液升温。

ΔT=K[cM+Bc2+⋯]
需要用已知分子量标样标定 K。

粘度

Newton 粘度定律：σ=ηdvdy（σ 剪切应力 Pa，dv/dy 速度梯度 s⁻¹，η 粘度 Pa·s） 遵守此式的流体叫 Newtonian；高流速下有些流体会 shear thinning（剪切变稀）。

Stokes 定律：Fvis=6πηs R v0，其中 6πη_sR 为摩擦因子 f

Einstein 定律（悬浮球）：

η=ηs(1+52φ+4φ2+⋯)
只依赖体积分数 φ，与球的大小无关。

用到高分子：把链视作流体力学等效球，φ = cN_Av V_h/M（V_h 为流体力学体积）：

η=ηs(1+c[η]+khc2[η]2+⋯),  [η] = 52NAvVhM

[η] 叫特性粘度（intrinsic viscosity），表示粘度随浓度增加的速率。

Mark-Houwink 方程：

Vh ∝ 43πRg3  ⇒ [η] ∝ Rg3M ∝ M3νM=M3ν-1
[η]=kMa,  a=3ν-1

链形态 ν a
致密球 1/3 0
θ 溶剂 / 理想链 1/2 0.5
良溶剂 3/5 0.8
刚性棒 1 2

大多数实际值 a 在 0.5–1 之间。粘度法测的分子量 接近 Mw，且 k、a 需标定或查文献。

实验装置： - 旋转粘度计：η = C × 扭矩/角速度 - 毛细管粘度计（Ubbelohde）：Poiseuille 方程

ΔVΔt = (ρg L+Δp)πR48ηL

Lecture 6 · 光散射与动态光散射

Rayleigh 散射

光的电场极化电子云 → 产生同频振荡偶极 → 向各方向再辐射。

IθI0 = 8π4α2(1+cos2θ)λ4 r2
  • I ∝ 1/λ⁴ → 短波长（蓝光）被散射得多得多 → 天空是蓝的 （正确说法：蓝光被空气分子强散射，我们看的是偏离太阳方向的散射光。不是"其他颜色被吸收/被海水反射"）（过去考题 Question 22）
  • (1+cos²θ) 项：小粒子的散射前后对称

极化率与折射率（Lorentz–Lorenz）：α≈n2-n024πVN，配合 n=n0+dndcc 得到

光学常数：

K=2π2n02(dndc)2λ4 NAv

气体：IθI0=Kc Mw1+cos2θr2

高分子溶液（小分子量）：

IθI0=Kc 1+cos2θr2·11Mw+2Bc+⋯
注意里面出现的正是渗透压的 virial 系数 B。

大粒子（> λ/20）：同一粒子不同部位的散射光相互干涉（destructive），强度净减少，且前向散射 > 后向散射（不对称）；唯一不受影响的角度是 θ = 0°。

IθI0=Kc1+cos2θr2·11Mw(1+q23Rg2+⋯)+2Bc+⋯,  q=4πnλsinθ2

所以静态光散射同时给出 M_w 和 R_g。

实验要点： - 样品必须无尘 - 浓度要低（粒子独立散射） - dn/dc 越大越好 → 应选折射率与高分子差别大的溶剂（过去考题 Question 23） - 测到的是 M_w 而非 M_n，因为每个粒子的散射按其质量加权

动态光散射 DLS

静态测时间平均强度 → M_w、R_g；动态测强度随时间的涨落 → 流体力学半径 R_h。

粒子运动 → 干涉明暗斑移动 → 强度涨落。小粒子扩散快 → 涨落快。（过去考题 Question 24）

时间自相关函数：

C(t') = 1T∫0T Is(t)Is(t+t') dt
- t' = 0：同一条曲线自乘 → 值最大 - t' → ∞：完全不相关 → 涨落乘积正负各半 → 平均为 0

结果是指数衰减：

C(t') = (⟨Is2⟩-⟨Is⟩2)e-2q2Dmt'+⟨Is⟩2

D_m 为互扩散系数，D_m 越大衰减越快。外推到零浓度得到示踪扩散系数 D_t：

limc→0Dm=Dt = kT6πηs Rh  (Stokes-Einstein)

布朗运动（与 Lecture 1 末端距同一套数学）：N 步、每步 l，均方位移 = Nl²，定义

Dt = Nl26t
（过去考题 Question 25）

Lecture 7 · SEC 与质谱

Size Exclusion Chromatography (SEC / GPC)

  • 多孔凝胶作固定相，溶液作流动相
  • 大分子进不了孔 → 先洗脱出来；小分子被孔滞留 → 后出
  • 记录保留体积 V_R，用已知 M 的标样作校准曲线，通常 log M 对 V_R 线性

两个固有问题： 1. SEC 分离依据是尺寸，不是 M → 标样的化学组成和结构必须与未知样相同，否则不准 2. 比孔还大的分子全部一起出来，V_R 无区分度

通用校准（Universal Calibration）：流体力学体积 V_h 相同的高分子有相同 V_R。

[η] = 52NAvVhM 且 [η]=kMa  ⇒  Vh∝kMa+1
ksMsas+1=kxMxax+1  ⇒  Mx = (ksMsas+1kx)1/(ax+1)

检测器： 1. 示差折光（Refractometer）——折射量 ∝ 浓度 2. UV-Vis——吸光度 ∝ 浓度（Beer-Lambert），高分子必须有发色团 3. 光散射——配合 (1)(2) 可给 M_w，可不需分子量标样 4. 粘度计——同上

⚠️ 过去考题 Question 26：UV 检测器的信号高度 ∝ n_i M_i。 理由：吸光度 ∝ 摩尔浓度（∝ n_i），但每条链上的发色团数目又正比于分子量，两者相乘。

从谱图算 Mn、Mw：由 ln M = kV_R + c 得 dM = k·exp(kV_R+c)dV_R，换元后对信号高度 h 积分：

Mn = ∫h dM∫(h/M) dM,  Mw = ∫hM dM∫h dM

MALDI-TOF-MS

MALDI（基质辅助激光解吸电离） - 激光脉冲作为"软"电离手段，防止高分子断裂降解 - 高分子 + 阳离子盐（Na⁺、K⁺）分散在吸收激光波长（通常 337 nm）的芳香族基质中 - 激光被基质吸收 → 迅速加热汽化 → 高分子进入气相，与阳离子或质子结合而带电 - 只适合含极性基团的高分子（聚酯、丙烯酸酯、酰胺），不适合非极性的 PE、PP

TOF（飞行时间） - MALDI 几乎只产生单电荷物种（极大优势） - 高压电场加速，F=ma - 同样电荷、同样电场 → 质量小的加速度大、速度快、先到检测器（过去考题 Question 27） - 由 qV=12 mv2 得 v∝1/√m，故 飞行时间 t∝√m - 数据给出各分子量物种的丰度 → M_n 和 M_w 都能算

MALDI 测得偏低的原因（过去考题 Question 28，答案是 D "以上皆是"）： - 高分子量物种更难汽化 - 高分子量物种在解吸电离时可能碎裂 - 检测器被先到的低分子量物种饱和，响应下降

各方法测什么 —— 必背对照表

方法 给出
膜渗透压、VPO、端基分析 M_n（依数性，数个数）
静态光散射 M_w + R_g
粘度法 M_v ≈ M_w
动态光散射 (DLS) R_h
SEC/GPC 整个分布 → M_n、M_w、PDI（需校准）
MALDI-TOF-MS 整个分布 → M_n、M_w

Lecture 8 · 玻璃态

玻璃的定义与形成

  • 玻璃是无定形固体：无长程有序，但不流动（区别于液体）
  • 热力学上不是最稳定态——亚稳态
  • 高分子中最普遍的状态

形成：熔体冷却 → 分子运动变慢、试图堆砌 → 低于某温度时已慢到无法重排到最优堆砌 → 这个温度就是 T_g。 这个过程与结晶竞争；只有一部分成功结晶时 → 半结晶态（semi-crystalline）。

玻璃态高分子的性质

  • 光学透明：链无规堆砌（像液体），折射率均一，不散射
  • 半结晶高分子发白/不透明：晶区与非晶区折射率不同 → 散射
  • 玻璃态易于从熔体加工（冷却即得）；结晶高分子需要精细控制结晶动力学
  • 结晶高分子力学强度通常更高，但高 T_g 的玻璃态高分子对很多应用已足够

体积-温度曲线（要会读图）

路径 含义
A→B→D→G 液体 → 结晶固体：在 T_m 处体积跳变，dV/dT 斜率改变
A→B→H→I 液体 → 玻璃态：体积连续，T_g 需外推两条线的交点求得
A→B→C→E→F→G 液体 → 半结晶：T_m 起结晶，剩余部分再玻璃化
A→B→J→K 更快冷却：分子来不及堆砌 → 体积更大 → T_g′ 更高

一阶 vs 二阶转变（高频考点）

(∂G∂p)T=V,  (∂G∂T)p = -S,   α=1V(∂V∂T)p,  Cp = (∂H∂T)p
熔融 T_m 玻璃化 T_g
阶数 一阶转变 二阶转变
跳变发生在 G 的一阶导（V、H） G 的二阶导（α、C_p）
V-T 曲线 跳变 连续，只有斜率变
α、C_p 曲线 尖峰 台阶（跳变）

仪器

TMA / 膨胀计（Dilatometry）：测体积膨胀，数据是 V vs T - 靠精确测高度变化推体积（要求各向同性膨胀） - 不规则样品可用填充介质（高分子用 Hg）：必须已知热膨胀系数，且不能与高分子反应/溶胀/溶解 - 也用于测热膨胀系数 α；DSC 测不出 T_g 时特别有用

DSC（差示扫描量热）：数据是 (∂q/∂T)_p vs T - 样品盘 + 空参比盘各在一个腔室，仪器维持二者温度相同并等速升降温 - 记录每升高 1 K 所需热量，减去空盘的贡献

⚠️ T_g 依赖热历史：慢冷 → 有更多时间堆砌得更紧密 → 外推得到更低的 T_g。 静置足够久，快冷样品会自行收缩到慢冷样品的体积 —— 这叫 aging（老化，不希望发生）。 为了数据可重复，TMA 和 DSC 都取第二次热扫描（heat-cool-heat-cool）来抹掉热历史。

T_g 与应用

T_g 范围 用途
低于室温 弹性体（交联成永久网络后有极大弹性）
室温 ~ 100°C 且不结晶 不适合做块体材料，但适合做胶粘剂
接近或高于 100°C 热塑性塑料（T_g 以上加工，冷却成型）
~200°C 工程热塑性塑料

影响 T_g 的因素

化学结构（T_g 是高分子开始软化的温度） - 主链柔性高 → T_g 低；主链刚性 → T_g 高（刚性芳环主链 T_g 高，如 PEEK T_g = 143°C） - 侧基越大越刚性 → T_g 越高（苯基、酯基等阻碍链运动重排） - 分子间作用弱 → T_g 低；极性作用（氯、腈、酯）→ T_g 高

分子量 —— Flory-Fox 方程：

Tg(Mn)=Tg(M∞)-KMn
分子量越低 T_g 越低（链端自由体积大）。低分子量增塑剂降低 T_g 同理。

交联：限制链运动 → T_g 升高

共混组成 —— Fox 方程：

1Tg = wATg(A)+wBTg(B)  (w 为质量分数)

更精确的熵推导版本：

lnTg = wAΔCp(A)lnTg(A)+wBΔCp(B)lnTg(B)wAΔCp(A)+wBΔCp(B)

⚠️ Fox 方程必须用绝对温度 K，用摄氏度算是错的。

Lecture 9 · 力学性质与加工

应力、应变、模量

σt = fA (拉伸应力),  ε=ΔLL0 (应变),  σt=Eε

E = Young's Modulus 杨氏模量，是应力-应变曲线的初始斜率（小应变下线性）。

  • Tensile strength 抗拉强度 = 断裂点的最大应力
  • Yield strength 屈服强度 = 开始出现不可恢复形变时的应力

泊松比 ν：

-Δdd = -Δhh=νΔLL0

三类应力-应变行为

类型 特征 例子
A 脆性 Brittle E 高，近似线性直到断裂，无屈服 PS、PMMA
B 韧性 Ductile 应力升到屈服点 → 塑性形变（不可恢复）→ 应变软化、大幅形变 → 断裂前 E 回升（应变硬化） PP、PE
C 弹性体 Elastomeric E 极低，无屈服点（形变可恢复），断裂应变 500–1000% cis-1,4-聚异戊二烯（天然橡胶）

温度与速率的影响

  • 升温 → 脆-韧转变（brittle-to-ductile transition）：韧性需要充分的分子运动和重排
  • 形变速率越快 → 表现越脆（分子来不及重排）

粘弹性（atactic PS 的模量-温度曲线）

区间 状态 行为
A-B 玻璃态（低于 T_g） 形变可恢复（弹性）
B-C 推迟弹性态（T_g 在此区） T_g 稍上链运动很慢；应变缓慢增加、缓慢恢复
C-D 橡胶态 模量出现平台；瞬时弹性响应 + 粘性流动 + 不完全恢复
D-E 橡胶流动态 模量进一步下降
E-F 粘流态 无弹性响应、无恢复，纯粘性流动

形变机理（三种，会区分）

机理 要点
Crazing 银纹 高分子中裂纹扩展的机理，导致脆性断裂。在拉伸的原纤（fibril）之间形成 10–20 nm 微孔洞；沿垂直于应力方向扩展；原纤最终断裂 → 断裂。银纹散射光 → 发白/发雾。能起银纹反而使材料强韧（把高分子拉成原纤的过程耗散了能量）
Shear Banding 剪切带 与应力方向成 ~45°；某小区域一旦剪切位移，因比周围未变形区更弱而继续扩展
Necking 细颈 韧性高分子屈服点之后立即发生；未成颈区应变小、所需应力低，所以颈部靠拉伸未成颈区而延长；整个样品成颈后模量回升（应变硬化）

加工工艺

工艺 要点
Extrusion 挤出 旋转螺杆把固体树脂送入加热料筒 → 熔融压缩 → 经 breaker plate（助压实、挡杂质）→ 通过口模（die）成棒/管/片
Compression Molding 模压 树脂放在加热开模下半部，上半部压下，多余料被挤出
Transfer Molding 传递模塑 树脂先装入传递腔，柱塞把熔体推入模腔
Injection Molding 注塑 合模后往复螺杆把熔体注入模腔（类似挤出），冷却后顶针顶出，在浇口处分离
Reaction Injection Molding 反应注塑 单体等先进混合单元，再注入模腔，聚合反应在模腔内发生
Thermoforming 热成型 塑料片加热软化 → 下方抽真空 → 贴合模具
Blow Molding 吹塑 先挤出中空管坯（parison）→ 合模 → 吹气膨胀贴合模具
Calendering 压延 熔体在两个加热转辊的小间隙中压成薄片
Coating 涂布 roll coating（下辊带液）/ blade coating（刮刀控厚）/ slot-die coating（直接挤到移动基材上）；涂层可用热或 UV 交联固化
Melt Spinning 熔融纺丝 熔体经喷丝板（spinneret）→ 空气冷却 → 导辊（godet）拉伸 → 卷绕
Dry Spinning 干法纺丝 20–40 wt% 溶液经喷丝板 → 热气快速蒸发溶剂
Wet Spinning 湿法纺丝 溶液经浸在非溶剂浴中的喷丝板 → 纤维凝固 → 辊收集
Electrospinning 静电纺丝 高压把带电熔体/溶液从小孔加速射向靶板，可拉到 100 nm 级细度；残余电荷随时间耗散

Lecture 10 · 弹性态与结晶态

弹性体的必要条件

  • 温度高于 T_g
  • 结晶度为零或可忽略
  • 必须交联
  • 模量远低于脆性/韧性高分子，但高度拉伸时模量升高
  • 形变完全可恢复

常见弹性体：cis-1,4-聚异戊二烯（天然橡胶）、聚硅氧烷（硅橡胶）、聚丙烯腈-丁二烯（丁腈橡胶）

硫化（Vulcanization）：用硫加热交联 cis-1,4-聚异戊二烯。机理尚不完全清楚，证据指向离子型反应。每个交联点是两条链之间的永久锚点，形成网络、保持形状，使链在形变后能回到原位。

橡胶弹性的热力学（重点）

dG=Vdp-SdT+f dL

由二阶偏导可交换：

(∂f∂T)p,L = -(∂S∂L)p,T

固定伸长率（如 350%）下测应力对温度： - 应力随温度升高而增大 → 斜率为正 → (∂S/∂L) 为负 → 拉伸使熵下降 - 熵下降的原因：伸展的有序构象构象数减少 - 低温处的反转点是玻璃化转变——此时已不是弹性体

由 G = H − TS：

f=(∂H∂L)p,T-T(∂S∂L)p,T
- y 轴截距 = (∂H/∂L)，实测接近零 → 拉伸几乎不把能量以焓的形式储存 - 应力几乎全部用于降低熵 → 橡胶弹性是熵弹性

绝热拉伸：无热交换，弹性功全变内能：

CV,pΔT=AEL22L0
→ 绝热拉伸橡皮筋会升温（可以用嘴唇试）。

结晶

能否结晶： - 立构规整（isotactic 全同、syndiotactic 间同）→ 能结晶（规整堆入晶胞的前提） - 立构不规整（atactic 无规）→ 不结晶 - 例外：带小极性侧基的有时也能结晶，如聚乙烯醇 PVA、聚氟乙烯 - 冷却动力学：留给堆砌的时间

结晶的好处：力学强度提高、抗降解性更好、阻隔性更好

三级结构：

层级 尺度
Unit Cell 晶胞 每边 2–20 Å
Lamellae 片晶（晶胞堆成的 2D 薄片） 厚 100–500 Å，宽数微米
Spherulite 球晶（片晶堆成的 3D 球） 数十至数百微米

晶胞约定：c 轴对应高分子主链方向（也叫 fiber axis），单斜晶系例外（是 b 轴）。 链先取最低能量构象（PE 是全反式），再尽量紧密堆砌。

XRD

2Dsinθ=nλ  (Bragg 定律)
D 晶面间距，2θ 是衍射角，λ 波长，n 整数。Cu Kα 时 λ = 1.54 Å。

  • 单晶：衍射花样取决于取向，多方向测量可给出唯一晶体结构和空间群
  • 粉末：各种取向的微晶都有 → 花样是同心圆环
  • 高分子样品容易做成粉末；2θ 由圆环到中心的距离得到；每个峰对应某个晶面或某个高级衍射（n > 1）

⚠️ 题目给的通常是 2θ，代入公式前必须除以 2。

T_m 依赖片晶尺寸

盘状片晶，半径 r、厚度 l。熔融时 ΔG_m = ΔG_b + ΔG_s = 0：

ΔGb=πr2 l ΔGVb,  ΔGs = -(2πr2+2πrl)γ

代入 ΔGVb=ΔHVb(1-TmTm∞) 并整理：

TmTm∞=1-2γΔHVb(1l+1r)

→ 片晶越薄越小，T_m 越低（表面能占比越大）。

T_m 依赖分子量

链端相当于杂质，造成熔点（凝固点）降低。

lnxA = -ΔHmnR(1Tm-1Tm∞),   xB = 2M0Mn

（每条链两个链端，M₀ 为重复单元分子量）

2M0Mn = ΔHmnR(1Tm-1Tm∞)

→ M_n 越低，链端分数越高，T_m 越低。

结晶机理与形貌

高分子按成核-生长（nucleation and growth）结晶：先出现稳定核，再从非晶相吸收链而长大。 片晶厚度由热力学 + 动力学共同决定： - 热力学上：薄片晶 T_m 低 → 低温才允许薄晶生长 - 动力学上：薄片晶生长更快 - → 低温下薄片晶占主导；当更薄的片晶在热力学上刚被允许时，生长速率会出现突变

形貌 形成条件
Spherulite 球晶 成核-生长的常规产物（如聚 L-乳酸）
Hedrite 片晶从中心张开时
Dendrite 枝晶 更深过冷下的无序生长
Shish kebab 串晶 在流动条件下结晶
