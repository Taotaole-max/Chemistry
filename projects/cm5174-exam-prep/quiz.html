考前最后一小时：八个必记陷阱

每条都在题库里对应一道题
  1. 1θ = 180° − 键角

    sp³ 是 70.5° 不是 109.5°，因子恰好 ≈ 2

  2. 2Mw 的分母是 ΣniMi

    不是 Σni；且 Mw ≥ Mn 恒成立

  3. 3ΔS / ΔH / ΔG 里的 n 是总摩尔数

    1 mol + 1 mol 要代 n = 2

  4. 4Flory-Huggins 只有高分子项除以 N

    φ = 0.5 时熵只减一半，不是 1/N

  5. 5ΔGmix < 0 不代表不分相

    判据是 ΔG 曲线的凹凸性

  6. 6渗透压公式里 c 用 g/m³

    1 g/L = 1000 g/m³，漏掉差 1000 倍

  7. 7Fox 方程必须用绝对温度 K

    而且不是线性加权，是倒数加权

  8. 8Bragg 定律：题目给 2θ，公式用 θ

    先除以 2 再取 sin

其余高频：t ∝ √m（不是 m） · I ∝ λ⁻⁴（四次方） · a = 3ν − 1 · Rg² = Nb²/6 · 1 mm² = 10⁻⁶ m²
