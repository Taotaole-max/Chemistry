## 2026-08-13 · 用 git 仓库做跨会话记忆载体

**背景**：本地 Claude Code 和云端会话之间不共享对话历史，云端容器还是临时的，会话结束就销毁。

**选择**：把记忆写成仓库里的 markdown 文件（`CLAUDE.md` + `.claude/memory/`），靠 git 同步。

**否决的方案**：
- MCP 记忆服务器（如 memory server）——需要一直跑一个服务、要么本地要么托管，云端临时容器连不上本地的；为了一个人的项目维护一个服务不划算。
- 只写 `CLAUDE.md` 一个文件——所有东西堆一起会撑爆，而它每次会话都自动加载，臃肿的代价是每轮对话都在付。

**代价**：记忆更新必须手动提交推送，且要合并到 `main` 才对其他会话可见。忘记推送 = 记忆丢失。

## 2026-08-13 · 带隙预测选随机森林

**理由**：小数据集（Materials Project 子集）上 RF 比神经网络稳，不需要调超参就能有基线，特征重要性可解释——对理解哪些描述符有用这件事本身有价值。

**代价**：外推能力弱，遇到训练集覆盖不到的材料体系会失准。
